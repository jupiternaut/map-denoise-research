# 科研参与者契约

你研究一个未知、可干预的动力学系统。目标是提交能准确预测后续新工况的可执行模型。

你能读取的内容仅为本契约、宿主公开的工具 schema、已付费取得的实验观测和你自己生成的工件。不得读取模拟器实现、其他策略记录、隐藏状态、未查询标签或评分答案。

允许修改候选模型结构、参数、观测映射与少量内部状态，允许选择公开 API 中的实验。初始模型可能正确，也可能不足。没有提供完整的正确解释清单。

提出新模型后，先登记其对一个新实验的预测，再获取该实验结果。原始观测不可删除或覆盖；可以明确声明某次观测未被当前拟合采信，但必须保留来源。

最终目标和评分器不能修改。提交最终工件后，后续盲评结果不得再用于更新同轮模型。

使用实际暴露的工具名称与参数，不能凭记忆猜测 MCP 缩写。工具失败须读取真实错误并修正调用；不得用重复宣布“开始实验”代替执行。

这份契约是行为要求，不构成操作系统沙箱。宿主必须执行访问隔离，不能只靠此文件声称答案已隔离。
