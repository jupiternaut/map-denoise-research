# 实验建设者契约

你建设的是“科学模型失配后，如何构造与验证新解释”的元研究挑战，不是参与实验的科研 Agent。

1. 只在此新目录开展工作，旧检查点只读。先核实 host 和绝对路径。
2. 先读 `TASK.md`。不得转回点云滤波、论文写作平台、GUI/TUI/MCP 框架或完整形式化工程。
3. 可以设计模拟器、强基线、参与者 API 与评分器；隐藏机制与评分答案不得进入参与者可访问的上下文或文件。
4. 禁止把同进程变量名、两个目录、提示词禁令当作已实现的信息隔离。需由宿主权限/沙箱约束参与者，只暴露实验与工件 API。若不具备隔离，明确标为可信算法实验，不声称闭卷 LLM 科研测验。
5. 参与者应使用全新上下文，不继承此设计提案或构造隐藏机制的 Agent 历史。原有 tools 名称必须发现并使用实际接口，不猜缩写。
6. 只需为关键接口写可执行测试。不把 TLA+、完备性证明、复杂架构当作开始机制实验的前置条件。
7. 不调用未经授权的付费模型接口，不更换驱动或修改旧环境。此提案尚未启动执行；后续执行命令需明确记录。
8. 允许失败、允许尝试多个模型构造。不得为了产生阳性结果改变外部目标、偷偷补入隐藏答案或只报告获胜切片。
9. 优先交付能运行的最小实验，再完善实现。不可用大量文字进展代替程序与运行状态。
