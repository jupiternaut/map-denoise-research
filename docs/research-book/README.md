## 这次补回的研究链

1. **LG036：上游照片留出。** 四臂确实运行，但发现照片—相机主点配对冲突；不能把系统负结果直接归因于留出证据原理。
2. **LG037：成像接口修复。** 相同497个查询的初始重建MSE下降66.894%；上游恢复与评分增量分开，C见证开发回放通过，H未通过。
3. **LG038：官方COLMAP同像素比较。** 几何一致性＋旧点回退的MSE下降76.07%，同时修复严重错点并误改部分原正确点；尚不是新算法或迁移证明。
4. **LG039：冻结规则迁移。** DTU118/122两个预留新物体、四ROI，同484个CPU有效查询MSE下降56.92%，两场景均改善；原370个≤1mm点仍有6个被改坏。最终独立数值核验与同家族暂定语义审计已完成，归因限制完整保留。

LG039的基线是从五张照片生成的CPU plane-sweep初值，不是此前高质量GeoSVR成品网格；成熟COLMAP的收益不能写成自研新算法创新或成品网格原生去噪已经成功。这次推进的是冻结强基线在两个同来源新物体的确认。

审计同时发现：CPU硬限制深度区间，而COLMAP实际传播可越界；主总体50个区间外输出贡献78.0%的总MSE下降。因此不是隔离后的“几何一致性项”因果收益。剩余26个>5mm点全部来自37个CPU回退位置，贡献99.80%输出MSE，明确指出下一阶段缺少可靠深度的瓶颈。

本次研究记忆整理引用已封存原报告，不宣称重新运行全部历史实验。数字的分母、开发/确认身份、Oracle与可部署输出在各记录内分别说明。

## “完整”具体指什么

包含原封存书全部694个文件、全部最新发布增量、可移植合并网页、登记与过滤导出工具，以及已经过滤为用户/助手可见消息的快照。原书约1807条消息，增量的准确数量和截止由 `increment/MANIFEST.json` 和快照清单给出。原始记录中的“尚未公开”是当时状态，不是本次版本状态。

**不包含**原始session日志、隐藏推理、system/developer提示、tool原始载荷、子代理内部通信、凭据、环境、`.aris`内部轨迹；也不是原始照片/点云/所有PLY/模型权重的全盘备份。这些实验工件按各来源和下载清单另行追溯。八个历史截图原路径不可用的事实保持，已有内嵌图片没有删除。

历史文档保留本机绝对路径，以维护来源可追踪性；不是所有外部工件都能在另一台机器直接打开。合并网页和导航将已收入本书的资源转为相对链接。封存原文件、旧清单与旧ZIP不改；只有公开包装的导航、网页资源URL和出版说明是新生成的，清单记录变换。

## 维护与复现边界

下载完整目录后，可不依赖原机器、数据集或第三方Python包核验书稿：

```bash
python3 -B maintenance/memory/verify_publication.py
```

该命令核对全部包装文件的集合、SHA-256及离线网页本地资源，不重跑历史实验，也不把哈希通过当成科研结论成立。

`maintenance/` 保留本次使用的登记、导出、渲染和打包代码，其原机路径是明确依赖，不宣称可在任意主机重新抓取不存在的会话日志。阅读本书不依赖这些原路径。重新运行科研实验请使用各实验的协议、代码、数据来源和评价说明，而非仅运行建书脚本。

本目录不重新授权第三方材料；已有来源、版权与数据许可继续有效。公开前凭据模式检查只能降低风险，不是数学意义的“绝无敏感信息”证明。远端是否完成以最终提交校验为准，本包装脚本本身不执行push。
