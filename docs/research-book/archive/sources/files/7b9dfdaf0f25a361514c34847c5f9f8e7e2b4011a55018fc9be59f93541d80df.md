## 优先精读的六组

1. COLMAP MVS 与 PatchMatch Stereo：明确本文候选与成熟构造的区别。
2. Hu–Mordohai 与 Poggi：核对代价曲线、匹配置信和几何收益标签的关系。
3. Friedman：解释实际使用的梯度提升回归，而不是泛称神经网络。
4. Bartlett、El-Yaniv、SelectiveNet：学习拒识和风险—覆盖，但不借用未满足条件的保证。
5. DTU 与 GeoSVR：核实输入、参考、相机和许可链路。
6. RIMLS、Pointfilter、IterativePFN：为同输入外部比较选择可实施的对口参照。
