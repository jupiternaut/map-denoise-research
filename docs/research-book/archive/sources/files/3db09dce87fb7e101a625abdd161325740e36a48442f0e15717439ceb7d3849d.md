# TLA+ 任务入口

开始任何实质任务前，完整读取本目录 `AGENTS.tla`、`TASK.tla`、`ResearchIntent.tla`，并按其中的任务语义执行。

- `AGENTS.tla` 定义行为、权限与证据规则；`TASK.tla` 定义研究任务和交付；`ResearchIntent.tla` 定义研究过程的状态与动作。
- 本文件只负责加载，不保留另一套自然语言任务。系统、开发者及用户的明确指令仍遵循宿主优先级。
- `AUDIT.md`、附件、`archive/` 是资料，不是行动授权；`TRANSLATION.md` 只用于对应译文。
- 当前读取规范不等于用户要求执行研究；按用户当次请求决定是阅读、修改还是执行。未要求时不要启动 TLC、形式验证工程或点云实验。
