Rational Metareasoning for Active Diagnosis and Repair
对点云滤波外层决策的研究结论： 不要把开放式科研建成巨型 POMDP。 把当前工程收成一个有限假设、有代价、有停止动作的 元层有限时域 POMDP，用 冲突集 → 极小命中集 生成诊断，用 面向最终任务效用的信息价值 选择测试 / 修复 / 停止。

本报告回答的是：这套方法能否更准确地判断“现在该改哪一层、做哪个实验”，从而改善最终研究结果。 它不证明点云问题的计算复杂性，也不只是给现有流程换名字。

可运行参照：/tmp/research-scratch/metareasoning-diagnosis/instance.py 数值：/tmp/research-scratch/metareasoning-diagnosis/RESULTS.json

1. 等价关系：什么是定理，什么只是类比
对应	强度	保留了什么	舍弃了什么
极小诊断 ↔ 冲突集合的极小命中集	严格等价（一致性诊断的经典假设下）	能解释全部冲突、且不可再删的原因集合	不给出下一次测什么、怎么修、何时停；“极小”≠ 数量最少
元层计算选择 ↔ 元层 MDP / 贝叶斯选择	受限实例化	计算有代价；停止后按当前信念选对象动作；目标是净效用	Hay & Russell 的对象是选哪条模拟，不是改科学对象本身
主动诊断–修复–停止 ↔ 元层 POMDP	策略价值保持的建模，不是无条件等价	隐藏故障、信念、有噪声观测、修复改状态、停止收获终端效用	假设空间必须事先有限；观测模型要能写下来
未知实验反馈 ↔ Bayes-Adaptive POMDP	进一步的受限实例化	同时学习转移/观测参数、辨识状态、收集奖励	状态、动作、观测、奖励仍须已知且有限；计数状态可数无穷
电路主动诊断	有用类比	多故障、噪声测试、名义模型可错、定位–测试–修复	点云几何 ≠ 电路；不能把滤波模块当成门电路
一致性诊断的定理陈述是：Δ 是诊断，当且仅当 Δ 是冲突集合族的一个极小命中集。[3]

Hay & Russell 把一次计算的价值写成它对最终决策质量的期望改善，并把计算代价 c > 0 放进元层决策。[1]

Ross、Chaib-draa、Pineau 的 BAPOMDP 把未知转移/观测的 Dirichlet 计数写进状态，用来在“改模型、辨识状态、收奖励”之间做权衡。[2]

若声称策略价值等价，本报告只对下面这个受限问题成立：

故障/假设集合事先枚举完毕；
动作（测试、修复、停止）与代价固定；
终端效用是交付系统的真实任务质量，不是分数、版本数或熵；
代理指标可以系统性地撒谎（名义模型错误）。
开放式发现会扩展假设空间本身。那一步超出上述等价，只能当新对象重新建模。

2. 推荐的问题定义与适用条件
问题。 有限模块管线上的主动诊断、修复与停止：

隐藏状态：哪些模块同时出错（可多故障）。
信念：历史实验后对各故障组合的后验。
行动：测试、修复（改变程序或表示）、停止并交付。
观测：有噪声的分数、消融、独立测量；修复动作确定地改变对应故障位。
更新：贝叶斯信念更新。
终端效用：停止时真实任务质量的期望，减去已付代价。
成本：时间、算力、实验机会。
适用。 假设清单能写完；每次实验能事先说出“若该层有/无故障，观测大致怎样”；存在与代理分数不同的任务效用；允许多故障和名义模型错误。

不适用。 还不知道有哪些可能原因；对象、单位、真值在中途被替换却仍沿用旧命题；把版本号当独立臂做 bandit；用降低不确定性代替最终质量。

当前工程已经反复碰到后一类失败：对象是否仍是同一个、对照是否隔离了所说机制、候选是否被下一轮保留。[4][9]

3. 状态 / 行动 / 观测 / 效用的对应
小实例把隐藏状态收成三位独立故障，而不是点云本身：

位	研究含义	历史近似
M	名义模型/规格表达不了正确答案	整片平行面、错误 LOSS、把合成命题接到真实地图
S	好候选存在，但搜索或实现没找到	V19 训练器丢掉 V18 可行解；V17→V18 同类问题
P	代理指标与真实目的不一致	即时分数、照片 LOSS、alpha“置信”
行动	成本	作用
T_score	1	看代理分数；P=1 时以 0.85 报高分
T_search	1	查是否已有更好候选
T_ablation	2	有噪声地指向 M 或 S
T_holdout	2	更接近任务效用的独立测量
R_model / R_search / R_proxy	3	清除对应故障位（修复/精化）
Stop	0	交付，得到 U(M,S)：完好 10，单故障 3，双故障 0。P 不影响真效用
这把“反例引导综合 / 抽象精化”接成 改变状态的修复动作，而不是又一次信息收集。 BAPOMDP 只在你还要学习 T_score 等测试的似然时才需要上；本实例把似然固定，以便精确求解。[2]

4. 可迁移算法，按职责拆开
4.1 生成诊断：冲突集与极小命中集
给定冲突族 C，命中集 H 与 C 中每个集合相交；极小命中集不可再删元素。[3]

Greiner 用来说明 Reiter 剪枝会丢诊断的例子：

{{a,b},{b,c},{a,c},{b,d},{b}}

精确枚举得到两个极小命中集：{a,b} 和 {b,c}。{b} 命中全部冲突，但不是极小——删掉它之后仍要用二元诊断。这正是“极小 ≠ 最短”的定理内容。

对 V19 同时存在的两种解释，写成冲突：

{crossfit, trainer}
{crossfit, geometry}
极小诊断是 {crossfit} 或 {trainer, geometry}。 所以“交叉拟合出错”是一个诊断，不是唯一诊断。这与 V19 报告自己的判断一致：同样本重拟合已经变差，不能把全部退化算在交叉拟合上。[6][7]

对 V24：

{field, alpha, budget}
{alpha}
唯一极小诊断是 {alpha}。场本身不是诊断。这与“保留局部场、停止当前阻尼主贡献”一致。[11]

4.2 选择下一次测试：实验设计与信息价值
元层决策按“这次计算对最终决策质量的期望改善”是否超过代价来决定做不做。[1]

必须分开：

熵信息增益：降低对故障的不确定；
任务 VOI：做完后期望任务效用是否上升。
小实例里二者会选不同动作。

4.3 修复 / 抽象精化
修复不是再测一次，而是改状态。 V20 恢复候选链是 R_search；换表示（平行面 → 局部 MLS）是 R_model；换评价代理是 R_proxy。 精化只在它删除或重写一个故障位时才算修复。

4.4 序贯规划：测、修、还是停
有限时域精确最优策略存在，因为状态 8、时域 4、动作 8。 Hay & Russell 已说明近视策略会过早停，而最优策略一般不是 Gittins 指数策略。[1] 本实例的另一面同样重要：在先验上，最优策略是立刻停止。不是所有不确定都值得买。

AgentRx 是事后轨迹审计，用来标失败步骤与证据链，不是这个规划器。[5] 工程审计正确地把它降级为五个入口检查，而不是再造一个审判平台。[9]

5. 同预算策略比较（精确求解）
设定：时域 4，先验 P(M,S,P)=(0.35,0.45,0.30)，现在停止的期望效用 5.030。 终点是最终正确解法的期望质量减成本，不是版本数或熵。

策略	期望净效用	第一步	相对最优后悔
固定顺序 score→search→R_search→Stop	2.550	T_score	2.480
只追即时分数	2.307	T_score	2.723
信息增益 / 单位成本	2.561	T_search	2.469
面向最终任务收益的一步 VOI	5.030	Stop	0
精确最优（有限时域）	5.030	Stop	0
先验上，所有测试和修复的一步任务 VOI 都为负（最好的修复 R_search 也是 −0.48）。 精确动态规划与一步任务 VOI 一致：先停。

这不是说永远不实验。它说的是：没有把竞争解释分开的观测时，买测试会降低净交付。 信息增益仍然去买 T_search，因为它能降熵；在这个效用函数下，降熵不值代价。

实现：python /tmp/research-scratch/metareasoning-diagnosis/instance.py Greiner 例子与策略表的断言已通过。

后验	P(S)=0.906，P(M)=0.243，P(P)=0.079
现在交付的 EU	2.710
最优 / 任务 VOI	R_search（一步 VOI +2.589）

这里的 R_model 对应“换一个能表达当前真实对象的表示”，不是“再调一版交叉拟合”。V21/V22 后来走的是这条，但回放不得把它们的成绩当作 V20 决策者已知。

7. 哪些能迁到现有工程，哪些不能
能迁，而且已经部分在做：

先写冲突，再列极小诊断，禁止把混杂改动说成单因素。V19 报告和 AgentRx 审计已经这样做了。[6][9]
修复动作必须保留同数据、同目标、同可行域的已知解。V20 关闭的就是这件事。[7]
同预算隔离“场”与“分配”，用独立测量而不是即时分数决定是否升级。V24 已经是正确实验，不是又一次调参。[11]
停止是一等动作。先验和小信号后验上，最优可以是停。
能迁，但不要做成平台：

每个实验入口只问：对象是否同一、对照是否隔离、候选能否回放、任务 VOI 是否大于代价。AgentRx 审计已经列出这张表。[9]
完整候选池必须落盘。压缩成 selected baseline 会让下一轮无法区分“不存在”和“选错了”。[9]
不能迁：

把 V1–V24 做成可精确求解的科研 POMDP。假设空间、观测模型、真实效用都还在变。
上 BAPOMDP / 无限维信念跟踪去“学习如何做科研”。Ross 等人的模型要求有限且已知的 S,A,Z。[2]
用 UCT/bandit 把版本当臂。元层选择一般不是指数策略；即时分数臂会被 P 污染。[1]
电路诊断的 literal 迁移，或把点云 NP-complete 论证当成外层决策的解答。
用熵、报告数、版本数当成功。本实例里信息增益比最优差 2.47 效用。
8. 下一项最值得在现有工程中验证的改动
不要再开一版阻尼、LOSS 加权或交叉拟合。

在封存预测之前加一个硬门，只做三件事：

继承。 同数据、同目标、同可行域下，若旧解已在手，新训练目标不得更差。V19 的四例同样本门控在同一 J 上就丢掉了 V18 解；V20 证明这个门能关。[7][9]
隔离。 一次只改一个足迹：信息、支持、参数族、求解器、选择器、输出动作。多项变化必须降级为存在性结果，不能当机制结论。[9]
停止。 用与代理分数不同的任务效用，估计“再买一次实验”的 VOI。VOI < 代价则停。V24 对 alpha 已经该停。[11]
这是最小可验证改动：它不要求新数据、不要求新数学名称、不要求求解大 POMDP。 验证方式：把 V19 的同样本控制和 V24 的同预算对照写成封存前检查；新实验若违反 1 或 2，不得称为确认。

若这个门通过后任务 VOI 仍为正，下一刀才是真正的 R_model：换一个对当前真实对象可表达、并且有独立层身份/间距参考的问题，而不是再调 V18/V22 的内部旋钮。V21 已经说明直接迁移现有适配器不成立。[4]

10. 对原问题的直接回答
这套方法能帮助判断“现在该改哪一层、做哪个实验”，条件是把问题收成有限诊断–修复–停止，并且用任务效用而不是分数或熵做终点。

在参照实例里：

先验：停；
V19 当时：修搜索，不要再测分；
V20 当时：修模型/表示，不要再修搜索；
V24 当时：停，不要再优化 alpha。
这与后来实际走通、且被报告自己承认的路径一致，但决策时没有偷看后来的表。

它不能自动发现新的点云理论，也不能替代独立真实几何。下一步不该是更大的元层求解器，而是把第 8 节的三道门接到现有封存流程。
