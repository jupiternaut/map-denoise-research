# 方法审计（只读）

已核对运行器、分析器、清单及36个pilot输出：误差复算差为0，K解析一致（identity无K）。

1. total_scale用配置√(1+a²)，非样本实际RMS，最大差0.022824mm。joint_forced同时改变σ和偏差先验，不能称纯σ敏感性；其余方法不使用该先验。
2. MAE/RMSE对应GT点身份；曲面“normal”仍是固定z轴，非局部法向或表面距离。曲面gap应称“GT形状校正轴向层距”；人为全塌缩输出原始层距0，该指标仍为0.043560mm。
3. 半层距错误率是点误差阈值率，层距丢失是层均值阈值代理，均非误合层/误分层计数；单面可另列K=2率。
4. 六法仅含官方Open3D ICP组件＋自研后端，非完整SOTA。先平均两次置换正确；54配对不等于54独立场景，幅度间也共享底样本。

建议廉价补查：全量结束后独立复算gap、阈值和K，检查每组两次置换齐全；另报曲面原始层均值差。不需重跑算子。
