# T3/T6 独立只读复核

复核范围：`tracks/t3_t6/geometry.py`、`local_operator.py`、`run.py`、
`extend_baselines.py`、`oracle_ablation.py`、`analyze.py`，以及旧 PCL/PathNet 适配器。
未改 T3/T6 代码或结果。

## 可进入导师汇报的事实

- 从保存的输出独立调用评估器重算 **16 例—方法组合**：四个 family 的 resolved-s0，
  各自 old_A、pursuit_reference、PCL-k8、PathNet；所有标量指标与记录 **差异为 0**。
- 普通算法分支只实际使用 XYZ；PCL 搜索半径由输入邻域距离计算，PathNet 使用冻结官方权重。
  未发现评估器的真值、面标签、旋转或噪声幅度流入普通候选。
- 主实验和外部扩展记录都没有执行错误。补测了小半径 PCL，未只选择易过平滑的大半径对手。
- 新的 matched_no_oracle 与旧 A-disabled 最大点差约 `2.19e-17 m`，适合作为匹配信息消融底座。
- 实际结果支持 **平面/槽板局部分层机制有开发期信号**，不支持所有曲薄结构：
  pursuit 相比旧 A 的 combined error 在双平面、槽板下降，在同心壳上升，在杆板近似不变。

## 必须明确的限制

1. **PCL 的 k 是全局搜索半径启发式。** 适配器取输入中第 k 近邻距离的中位数，再传给官方 MLS；
   不是逐点恰好 k 个邻居。测试是固定二阶多项式、有限半径网格，不能代表所有 MLS 配置或所有结构保真方法。
2. **旧 oracle_association 不是孤立关联消融。** 它在每个真分量中重新查询 k 个邻居，并使用直接平面投影，
   同时改变支持范围和更新规则；其曲面退化不能推出“正确关联无用”。应优先使用已追加的 matched-oracles。
   即使 matched oracle 也只是特定求解器下的诊断，不是所有方法的可达误差下界。
3. **rod_plate 不使用 balance 参数。** 各条件都固定约 72/28 的板/杆采样；名为 imbalanced 的条件在该 family
   实际改变 gap/sigma，但没有测试采样不平衡。已提醒负责代理在报告解释，不要求重跑本轮。
4. **slotted_sheet 的双面厚度恒为 5 mm。** gap 控制横向槽宽，而非两面的厚度。
   不应将四族同名条件概括成同一个法向层间距扫描。
5. **间距与侵入率是几何诊断，不是拓扑证书。** estimated_gap 依赖最近真表面分组后的中位值；
   不能单凭该值证明输出确有两个可分的连通表面。component recall 与 intrusion 联合解释更稳妥。
6. **槽边指标可能部分来自其双面的去噪。** 候选以局部平行平面对为主要机制，slot_edge_recall 上升不等于
   已经纠正切向跨槽融合，需要区分上下双面保留与横向槽边恢复。
7. 均是已暴露程序化几何族、受控 IID XYZ 噪声、零帧偏差。新种子/参数复测不是真实 CAD 或真实扫描迁移。

## 复算得到的总体数值（mm）

| 方法 | combined | 单向表面误差 |
|---|---:|---:|
| old_A | 1.683226 | 0.760497 |
| pursuit_reference | 1.634783 | 0.687032 |
| pursuit_disabled | 1.700279 | 0.784667 |
| matched_association_oracle | 1.614428 | 0.659750 |
| matched_both_oracle | 1.607982 | 0.652426 |

这些值没有证明论文新颖性；它们支持继续定位可复用的关联机制，而不是把 oracle 或程序化几何收益包装成成品。

结论：**没有发现使当前数值比较整体失效的实现或评估错误；建议采用 matched oracle 解释机制，
明确 PCL 半径语义与形状条件差异，保留曲面失败和算力代价。**
