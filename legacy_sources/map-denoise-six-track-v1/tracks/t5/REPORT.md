# T5：保持既有输出的 EM 实现优化

## 导师摘要

**实际实现并验证了约 4.4 倍的单线程 CPU 加速；无需 CUDA，也没有减少 EM 迭代数。**
28 个开发测试的逐点混合分支与最终分层分支均没有变化，最大最终点差
`2.018e-11 m`。这是一项计算实现成果，不是新增几何收益，也不是独立方法论文的充分证据。

更直接地回应“原型慢 31 倍是否就是算法极限”：在本轮相同 16 个普通几何案例上，
相对原有向量化双边滤波实现，旧参考慢 **30.728 倍**，新实现慢 **7.057 倍**。
原型成本显然不是固定下界，但剩余开销也没有被消除。
双边滤波是既有经典自实现、默认参数不同；此处只作成本背景，不冒充新的官方强基线复现。

## 本轮究竟构造了什么

旧参考：`parallel_geometry_v5/association/operator.py`，只读导入；默认 k=48、两次外层更新、
每次两组初值、每组 32 次 EM；fallback=bilateral。

1. **fused**：C++ float64 单线程行融合核。在一个邻域内部复用两条责任数组，
   直接计算二分类责任，减少 N×K×2 的反复分配、指数/对数调用与数组遍历。
   保留初值、迭代数、共享方差模型、阈值、后续平面拟合和位移规则。
   编译采用 `-O3 -fno-fast-math`。BIC、分离度、支持度距决策阈值不足 `1e-8` 的行退回旧参考。
2. **fused_screen**：另加必要条件预筛。若双高斯最大可能似然或分离度仍达不到选择阈值，
   就不执行该行 EM。被筛掉的行继续原双边 fallback，不删除点、不修改阈值。

对残差 x、邻居数 K、方差下界 v_min：

\[
\ell_2\le -\frac K2\log(2\pi v_{\min}),\qquad
\mathrm{sep}\le\frac{\max x-\min x}{\sqrt{v_{\min}}}.
\]

前一个界来自任何混合密度都不超过最高分量峰值；后一个界来自 EM 均值为观测的凸组合。
实数模型下，界不足即可排除双层分支；浮点实现另留裕量并测试。
**这不是对所有浮点输入的等价形式证明。** 筛掉行的混合拟合诊断使用占位值，
只保证本轮检验的选择和最终点输出一致；不要将其 two_loglik 当作真实执行过 EM 的结果。

## Profile 与成本

旧参考在 1500 点平面案例：总计 `0.693 s`，fit_modes 累计 `0.641 s`，约 **92.5%**。
因此本轮优化 EM，而没有先改邻居树或执行 GPU 移植。

| 范围 | 旧参考 | fused | fused_screen |
|---|---:|---:|---:|
| 25 个非恒等开发例：各例热态中位时间之和的比值 | 1× | **4.369× 加速** | **4.422× 加速** |
| 10000 点薄结构：三次运行中位时间 | 4.707 s | **1.098 s** | **1.088 s** |
| 10000 点：5 ms 采样的进程 RSS 峰值 | 172.23 MiB | **143.49 MiB** | **143.86 MiB** |
| 1500 点薄结构：新 Python 进程内首次去噪中位时间 | 0.674 s | **0.159 s** | **0.155 s** |
| 同上：包含启动、导入、输入及库加载、退出的子进程墙钟 | 0.873 s | **0.354 s** | **0.355 s** |
| 同上：新进程 RSS 峰值中位值 | 84.27 MiB | 81.76 MiB | 81.24 MiB |

编译一次耗时 `0.382 s`，单独报告，不藏在热态数字中。
普通运行 RSS 采样峰值总范围约 94.0–112.1 MiB；它包含 Python、数据和已有分配，
不是核本身的独占内存。10000 点逐臂峰值在同一进程、顺序执行，不能当成严格独立进程内存对照。
冷测是新 Python 进程，但未清空操作系统文件缓存。未使用 GPU，显存成本不适用。

计时每例每臂三次，普通例交替次序，BLAS/OpenMP 均限制 1 线程。
机器仍可能有其它研究任务；这些是开发环境观测值，未给出隔离硬件上的置信区间。

## 输出与决策检验

- **28 例**：4 个既有暴露形状族×2 种扰动×2 个开发种子，共 16 例；
  7 个层间距/噪声比；精确平面、共线、全重复、空输入、单点。
- 两臂各对照 **58200 个点—迭代位置**，逐点 `choose_two` 和几何 `split` 均 **0 差异**。
- 28 例最大最终点位置差 **2.018e-11 m**；16 例几何评分最大差 **1.825e-11 mm**。
- 单独 10000 点案例最大最终点差 **1.366e-11 m**；该补充只检查输出，不另宣称逐点分支全同。
- 550 行残差×6 种阈值配置×2 臂，共 **6600 行—配置—实现比较**；
  包含 BIC 阈值恰好相等与相邻浮点数、分离度和支持度边界，混合选择均 **0 差异**。
- 旧参考的 8 项单元性质分别在三实现上运行，共 **24 项通过**：包括似然检查、单/双模态、
  方差下界、变换一致性、非破坏输入、退化输入、参数验证和位移上限。
- 输入、三个最终输出、每次迭代两个分支位图均保存；输出先保存，再调用几何评估。

本轮采用 `1e-9 m` 最终点最大差作为实现验收容差，实际差异更小。
结果不是逐位一致，不能据此推导全输入正确性或拓扑等价；尤其没有网格，不能宣称网格拓扑证书。

## 不应隐藏的负面结果

解析预筛在普通带噪数据上基本没有额外获益，有时比 fused 稍慢。
10.18×（精确平面）和 11.02×（共线）的总加速依赖容易预筛的退化/无噪输入，
**不能作为一般点云速度宣传数字**。当前默认建议使用 fused，把预筛保留为可选分支。

尚未实测百万点、真实地图、3DGS、高并发或 GPU；没有证明真实数据上能保持旧算法的几何收益。
同一误差被更快计算仍是同一误差，T5 不解决薄层与扫描重影的物理混淆。
后续只有当其它轨道证明几何价值时，才值得继续工程优化；不能把 T5 的明确加速当作整体课题已经成功。
