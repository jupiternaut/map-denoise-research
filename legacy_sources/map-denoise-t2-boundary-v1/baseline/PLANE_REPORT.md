# 共面斜率联合估计：专用平行面滤波器

## 本轮实际新增

旧 `scalar_reference.py` 保持不变。新增并冻结 `plane_profile.py`，
SHA256：`df84283f8bc496acccd94b53dcc281198e0368676d5aa739d934715407c3df6b`。
唯一主方法 `plane_profile_map`，仍为 `estimate(Input, method) -> output, bias, info`。

目标是修复“已有局部坐标的近似法向有小角度误差”导致的错滤，不宣称处理一般曲面。
模型从 `z=a_f+d label` 扩为：

\[
z_i=a_{f_i}+\beta(x_i-x_0)+\gamma(y_i-y_0)+d\ell_i+\epsilon_i.
\]

每帧比例自由。XY 居中/缩放只用于数值求解，不输入真值法向。
以零斜率、去除帧均值后的 XY 回归两组初值，分别结合三个 gap 初值，
使用解析梯度 L-BFGS-B 联合估计斜率、frame 截距、共同间距和混合比例。
始终比较单面解释与双面解释。候选选择只使用相同观测似然及固定复杂度分数。

零斜率初值不能省略：raycast 数据中面标签与 x 相关，单纯回归可能把真实层间距解释为倾斜。
本轮在有物理遮挡的 raycast 数据上也实际运行了这两组初值。

输出不再只改 z。令 `n=(-β,-γ,1)`，移向公共几何面的更新是

\[
p_i'=p_i+\frac{\mu_0+d\widehat\ell_i-[z_i-\beta(x_i-x_0)-\gamma(y_i-y_0)]}
{\|n\|^2}\,n.
\]

即沿估计法向做正交 MAP 投影，同时消除 frame 偏差；报告的 frame 偏差与 gap 均换算为法向距离。
MAP 可保持两层间距，但误分类时仍可能跳错层；没有隐藏这些风险。

## 限制与判读

- 这是同斜率平行面与共同法向 frame 偏差模型；不解决每帧不同斜率或真实曲率。
- σ 仍按近似 z 条件噪声使用，没有估计坐标相关的 errors-in-variables 协方差。
- 无 WAIT、无严格 bias 盒约束。原来的不可辨识隔离双层仍没有凭空增加证据。
- 对照与新方法同时存在 MAP/后验均值及三维投影的实现区别，因此这张表是完整方法效果对比，
  不是只将 β、γ 一项改动后的严格单因素贡献归因；根线程可复用旧 scalar-hard 作为额外对照。
- 这轮收益来自补上真正缺少的平面方向变量；比继续在错误固定法向下增加 EM 迭代更有作用。
  尚未建立真实传感器、非平行结构或投稿新颖性。
