# 专用滤波器的核心：区分帧偏差、层占比与表面方向

本轮不以完备性或形式验证为任务；这里只解释实际算子为什么这样构造。

## 1. 逐帧去均值为什么会伤害结构？

考虑局部近似平行的两层。第 f 帧中第二层的采样比例为 p_f，层间距为 d，观测为

\[
y_{fi}=a_f+d h_{fi}+\epsilon_{fi},\quad h_{fi}\in\{0,1\}.
\]

a_f 是共同第一层位置加这一帧的法向偏差。于是
`E[frame mean] = a_f + d p_f`。
对齐帧均值会同时移除 `d p_f`，把真实层占比变化误当成偏差。

## 2. 可以不先猜对每帧偏差

给定候选间距 d 与这一帧的分层 h，最小二乘的最佳截距可直接求出：

\[
a_f^*(d,h)=\bar y_f-d\bar h_f.
\]

在硬分类 profile 子问题中，这一步消去偏差变量。去掉截距后，平方误差为

\[
\mathrm{SSE}_f(d,h)=S_f-2d C_f+d^2 Q_f,
\]

其中 `S_f=sum (y_i-mean(y))²`，`C_f=sum (y_i-mean(y))h_i`，
`Q_f=n p_f(1-p_f)`。直接把最优截距代回并展开平方即可得到。

对 d≥0，把一帧的坐标从小到大排序，再枚举切分位置 q 即可枚举其有序双层硬关联。
相同高层点数下，交换次序不一致的两点会增加或保持平方误差，因此不必枚举 2ⁿ 个标签。

加入当前分类似然所用的比例项后，实际参考搜索的是

\[
\Phi(d)=\sum_f\min_q\{S_f-2d C_{fq}+d^2Q_{fq}
                      +2\sigma^2 n_f H(p_{fq})\}.
\]

H 是二元熵。每帧对 q 独立取最小值，只剩共同 d 的一维搜索。
实现使用有限网格加局部一维细化，不宣称求得所有输入上的全局最优。
普通点云只提供观测，不提供真实层标签；一层和两层通过显式模型分数比较。

对应代码是 `_profile` 及无参照输入的 `scalar_profile_hard`。它也是后续联合求解的
初始化组件；`scalar_profile_lbfgs` 和 `plane_profile_map` 最终仍显式优化各帧截距，
不能把完整联合滤波器称为一维消元算法。

## 3. 输出的是实际去噪几何

搜索得到间距、每帧截距与关联后，以固定共同平移约定消除帧偏差，并将点放到其
关联的层上。hard/MAP 输出避免把两个层中心按概率平均成中间的虚假表面；soft
后验平均在身份误差较大时可能有更低的均方误差，两者应分别测量。

更实用的扩展允许局部平面略有倾斜：`z=a_f+βx+γy+d h+ε`，共同估计 β、γ 后做
三维正交投影。它仍是局部近似平行表面的专用滤波，不是全场景三维重建。

具体求解：同时拟合一层/两层的高斯混合似然，每帧使用自己的层占比；用零斜率与
帧内回归两类初值，L-BFGS-B 求解，再按固定复杂度分数选择模型。最终 MAP 关联后
沿共同法向投影到去除相对帧偏差后的表面。帧占比、帧偏差、共同斜率分别解释不同变化。

## 4. 这段推导支持到哪里

它证明了固定关联时的截距消元式，以及平方误差下的有序切分性质；解释了为何
硬分类参考无需把帧偏差全留在高维搜索里。它没有证明混合模型或变量消元是新方法，也没有
替代与已有算法的实验比较。原型收益和最终采用哪个算子由实际保存输出决定。
