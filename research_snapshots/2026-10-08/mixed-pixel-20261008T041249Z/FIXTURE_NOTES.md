# E1 fixture and E0 producer contract

Host and root: `liekkas`, `/srv/slam-research/grf/map-denoise/runs/mixed-pixel-20261008T041249Z`.

The fixture generator is independent of predictor.py and every historical renderer. It copies no scoring or rendering implementation. It reconstructs the prescribed supplied camera matrices from `Ry(±.07) @ Rz(±.11)`, focal length160, principal point(64,64), and camera centers(±60,0,0); a unit test compares these with the read-only historical camera values.

`create_e1(output_dir)` is the only complete-data entry point. It creates 24 base groups plus12 alternative-background worlds. Four mechanisms, half-widths1.65/2.65 and seeds1103/2207/3301 are exact design factors. The source includes no E1 evaluation and refuses to overwrite existing observed/truth/oracle directories. It must be called by main only after the source lock and E0 gate. Unit tests serialize just one separate temporary negative-control world and remove that temporary unit artifact.

The two-plane foreground is a rectangle with local reference-projection half-width equal to the design factor, half-height8px and rotation0.17rad. Seed-dependent center offsets are uniform in[-.18,.18]px about(64,64); query(64,64) remains foreground. Foreground optical depth600 and background optical depth900 are producer-only truth. All backgrounds lie behind the foreground. A textured single scene has one unbounded foreground plane; its width factor remains a bookkeeping factor without physical effect. Flat-equal scenes retain hidden geometry but the complete three-image tensor is a single constant per seed, with no geometric image cue.

Pixels use independent world-ray/plane intersection and a3×3 equal-weight midpoint kernel with offsets{-1/3,0,1/3}². Foreground occupancy uses inverse rotation and rectangle inequalities. Textures are continuous bounded trigonometric fields, with four fixed frequencies and seed phases. The oracle receives only128×128 reference-coordinate array samples, so its common order1 interpolation may differ slightly from continuous generator radiance between samples. No method receives the texture formulas or phases.

Background pairing changes only the background mean and texture phases. Target geometry, target radiance, supplied cameras, and pixel kernel are identical across each pair. Flat-contrast pairs preserve two unequal constant fields. Flat-equal and single-plane worlds have no background alternative.

Observation IDs are opaque wNNN and a fixed random permutation breaks direct factor ordering. observed/inputs.json contains only id, cameras, image_file and sha256; observed NPZs contain only images. truth/metadata.json holds grouping, mechanisms, seeds, target depth and producer details. oracle NPZs contain mode, foreground, background, mask, polygon, background_depth, valid, auxiliary_valid and sigma_valid. Polygon vertices use reference(x,y), counter-clockwise order, without a repeated final vertex. Empty single-plane polygons accompany an all-ones mask. Oracle auxiliaries never contain true target depth, source-view ownership, seeds, phases or class labels. Sigma validity is false until the runner attaches the shared estimate-derived scale. Arrays cover the whole reference field for the common frozen nearest extrapolation rule.

E0 uses a separate analytic implementation: clip a unit pixel square by a slanted half-plane, compute polygon area by shoelace, and compare against dense midpoint sampling at32/128/512/2048 samples per axis. Positive depth discrimination comes from the analytic projection `x_source=x_reference-f*b/z` under a nonzero rectified baseline. The same-color control removes it. An additional nine-subray calculation fixes the exact foreground ownership bits while retaining a linearly textured candidate warp, with hand-computed expected pixel values. These checks establish numerical/physical contracts, not E1 algorithm performance. Predictor integration tests are recorded separately when its implementation is available.

`test_integration.py` adds four E0 contracts against the shared predictor without generating E1: one independently rendered flat-contrast world under both supplied rotated cameras; one full-image equal-color world under both modes and all three incumbents; a hand-built analytic slanted half-plane under a rectified nonzero baseline; and a hand-built linear texture with independently computed frozen subray ownership. `e0/INTEGRATION.json` records the source hashes, raw checks and results. All four passed. The generated constant-color pixels match true-candidate shared predictions exactly; analytic expected pixel values and fixed-alpha texture values agree within1.43e-14. Equal-color losses remain flat at8.08e-28, a harmless constant floating-point residual. Source auxiliaries remain unchanged and raw oracle prediction is available with sigma_valid=false.

Implementation error log: none. All fixture, analytic E0 and shared-predictor integration checks passed on their first run. No existing E0 result was overwritten and no method code was changed by the fixture/integration agent.
