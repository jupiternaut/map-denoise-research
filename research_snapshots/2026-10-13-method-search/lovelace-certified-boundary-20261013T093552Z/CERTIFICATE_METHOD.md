# A13 精确排除核

`cert_kernel.ExactContext(observation)` 只读 `photo/camera/appearance`。搜索先使用冻结 A12 的浮点必要条件得到不可行提案，再调用 `check_cell(branch, lo, hi, deadline)`，其中 deadline 是 `time.perf_counter()` 的绝对截止值。只有返回 `verified=true` 可以排除闭区间。错误、超时、无正证书均为保留。构造器记录 `setup_seconds/setup_cpu_seconds`；每次调用分别返回几何与约束构造、浮点证书搜索、精确核验及总墙钟/CPU 时间。

## 从输入到有理数必要条件

物理常数来自原任务：像素宽 `1/20`、高 `2/75`、面积 `1/750`；首个左下边界为 `(-1/5,-2/25)`。所有矩形整数边界、720 后景深度、视图中心、噪声及颜色变化界均为该任务的有理数。代码不导入浮点 renderer，不对浮点面积系数事后取分数。元数据须与冻结常数的 binary64 表示一致，否则返回 unknown；未填写可选元数据时沿用同一冻结常数。

冻结 A12 `data_builder.public_packet/float_tree` 对原有理数观测执行 `float(exact_rational)`，然后 JSON 保存。对此处每个 photo、u、coupon、reference 的有限 binary64 值 x，取相邻浮点数 prev、next 的精确有理数，观测真值包含于闭区间 `[(prev+x)/2,(x+next)/2]`。两种 tie endpoint 都保留，因而不需要依赖偶数舍入的边界选择。clip 后观测再与 `[0,1]` 相交。此包围明确覆盖输入序列化误差；精确主张针对生成器的冻结有理数模型，不能扩展到其他采集或序列化约定。搜索选择的 lo/hi 则是自身精确 binary64 有理数 `Fraction.from_float`，不另扩张；由共享边界的区间划分维护覆盖。

独立相机消元：residual 区间为 `-1000*u-center`。共享 k 取中视图残差加减 `1/100` 与 `[-1/100,1/100]` 的交；边视图 e 取残差减 k 再加减 `1/100` 与 `[-1/5,1/5]` 的交。中视图相机固定 0。这丢弃了剩余跨视图相关性，因此是必要条件的外放松。

每个投影边界在深度/相机矩形上的极值由角点取到（深度正）。由此构造统一内外矩形。左右材料面积下/上界分别是内/外矩形与像素交的面积。后景为 `rear_inner \\ front_outer` 的面积下界和 `rear_outer \\ front_inner` 的面积上界；同一包围后景同时出现在差集两项。所有运算为 Fraction。使用 A12 free 的矩形表示，不使用旧连续求解器的 Lipschitz 收紧，也不依赖独立区间系数同时取极值的可达性。

15 个变量依次是 `d0_0,d0_1,d0_2,d1_0,...,d2_2,b0,b1,b2,ba0,ba1,ba2`。其中 d=1-c∈[0,1]；照片 b∈[-1/100,1/100]；独立外观 ba 的相同初始界由 reference 进一步截取。绝不强制 b=ba。coupon 产生 d-ba 的上下界，同材料任意视图对差值界为 ±1/10。照片通道根据 clip 饱和状态产生共同灰度加 b 的上下界；使用面积下界形成下读数必要约束、面积上界形成上读数必要约束。饱和为 0 时无下读数界，为 1 时无上读数界；观测舍入区间的端点决定是否可使用该方向。

## 证书

有理数行按 `A x <= rhs` 保存，盒约束另存。固定行顺序为：按 v,k 的 coupon 下读数行（d-ba）及上读数行（-d+ba），然后按 k,v,w<v 的正负材料差行；随后每视图依次为按像素递增的照片下读数行、上读数行。不适用的饱和方向省略。

单线程 HiGHS Phase-I 浮点 LP 最小化 t，约束 `A x-t <= rhs`、x 在盒内、t≥0。每次求解截止不超过剩余时间与 0.20 秒的小者。其行对偶值只用于提出非负稀疏乘子 y。取其 binary64 精确有理数，计算 `a=Σ y_i A_i`、`β=Σ y_i rhs_i`、`m=Σ_j min(a_j lower_j,a_j upper_j)-β`。仅当 y 全部非负且 m 严格大于 0，才得到任何盒内点均违反组合约束的矛盾。不需要浮点 LP 最优性、浮点状态正确性或 exact cancellation，也无核验容差。

JSON schema 为 `a13-rational-box-farkas-v1`；字段包括 branch、lo/hi 有理数字符串、稳定变量序列、row_count、稀疏 `[row_index,"numerator/denominator"]` 乘子及精确 margin。绑定输入的 SHA256 使用三个公开字段的 canonical JSON（sort_keys、逗号/冒号紧凑分隔）；这是记录关联校验。独立验证器重新读取公开数据、重建物理必要约束并计算同一严格矛盾，不接受证书自报的矩阵或 margin 作为事实。

## 测试与边界

`test_cert_kernel.py` 核验有理数面积包围（含边界、内部点及全部遮挡支）、算术符号、舍入包围、饱和照片、全白不可辨识、b 与 ba 独立、零预算及非法元数据。只从 A12 开发集读取六个世界，利用开发真值构造实际 15 变量 witness 检查所有必要行，并检查真值小区间不能被排除、三个有对比度世界的远端小区间可以得到正证书。确认集在冻结前不可读取。

2026-10-13 在 liekkas、指定既有 Python 环境、四项线程变量均为 1 下，两次测试均通过：180 个精确面积样本、六个可行开发单元、三个远端排除。第一次测试体 CPU 0.876 秒；第二次用于测量完整冷进程成本，测试体 CPU 0.831 秒，`/usr/bin/time -p` 记录 real 1.71、user 1.03、sys 0.03 秒。两次测试体 CPU 合计 1.707 秒；第二次完整进程 CPU 1.06 秒，第一次未做完整进程 resource 计量。三个远端证书分别有 1、1、4 个非零乘子，单调用墙钟约 4.6–7.6 毫秒。以上是开发单元成本，不是正式批次性能。

证书证明的是此有理数必要条件系统不可行，继而排除冻结模型内该分支/深度区间。它不证明通用真实成像模型、噪声分布或跨机制迁移；不能核验的提案保留。
