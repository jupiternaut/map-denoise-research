# 原始问题：从有界误差的三幅照片修订一个深度

目标：真实深度未知，给定一次成像观测与一个现任深度，输出更准确的深度，同时尽量保留本来正确的现任。单位 mm。你可以自由选择数学表示和相适配的求解器，不指定路线。

## 场景和观测（全部是问题的物理定义，而不是指定求解状态）

相机针孔、焦距归一为 1，中心为 (-80+e0,0,0),(0,0,0),(80+e2,0,0)，朝 +Z；e0,e2∈[-0.2,0.2]。前方矩形 F=[-20,20]×[-15,15]，深度 z∈[540,660]。左右半片是两种材料。后方深度720，可能不存在（none）、矩形[-20,36]×[-17,23]（partial）、矩形[-100,100]×[-80,80]（full）；分支未知。背景灰度1。表面不透明，逐射线先遮挡后在每个像素面积积分，不是中心射线采样。

三幅照片各8×6，归一像平面范围 u∈[-1/5,1/5],v∈[-2/25,2/25]，按行从v最小到最大、列从u最小到最大，RGB连续排列。每个视图每种材料有灰度 c[v,k]∈[0,1]；同种材料跨视图最大值减最小值≤0.1。RGB理想值相同，像素/通道误差可不同。观测为 clip(I + b[v] + eps,0,1)，其中 |b[v]|≤0.01、每通道|eps|≤0.01。没有已知噪声概率分布。

独立相机测量：标靶标称 Xf=0,Zf=1000；u[v]=(-C[v]-e[v]-k-nu[v])/1000；共享标靶误差 |k|≤0.01，三视图定位误差 |nu[v]|≤0.01。中相机 e[1]=0。

独立外观测量：coupon[v,k]=clip(c[v,k]+ba[v]+transfer[v,k]+noise[v,k],0,1)，reference[v]=clip(0.5+ba[v]+noise_ref[v],0,1)。|ba[v]|≤0.01，|transfer|≤0.005，|noise|,|noise_ref|≤0.005。ba与照片b独立，不可强制相等。

`forward.py` 提供这个模型的浮点理想照片实现；实际生成使用冻结的有理数实现，二者会独立核对。不要把浮点拟合当精确证明。共享代码不包含求解器。

## 方法接口

交付单一 `method.py`：
```
prepare(observation: dict, budget_seconds: float) -> JSON-serializable state
decode(state: dict, incumbent: float) -> float
```
observation只含 `photo`（432浮点数）、`camera`、`appearance`：后两项按上面定义，camera有u/Xf/Zf/survey_bound/localization_bound，appearance有coupons/references/bias_bound/transfer_bound/noise_bound。没有task ID、类型或真值。输出必须有限且在[540,660]。一次观测的prepare可复用于不同现任，但decode每次只收到一个现任，不能从一组现任推断它们的生成中心。state不能含真值。可返回集合、参数、因子、程序等任何可JSON化对象。不强制使用共同求解器或证明格式。

预算：单线程CPU；正式每观测prepare预算6秒与24秒两个截面，须自行检查截止；超过预算0.25秒的原子步骤要记录。硬限额另加2秒，超限计失败并用identity回退；不删失败样本。numpy/scipy可用；不调用网络/LLM/API/GPU或安装。不依赖其他臂或历史结果。开发构造给一次提案及最多一次基于开发数据的修订，20分钟墙钟、累计开发运行CPU≤120秒。不是要求耗完预算。

`dev.json`（稍后提供）包含6个开发观测及开发真值，可用于开发评价，但方法prepare/decode只能使用上述输入。确认数据将在方法冻结后生成，构造者不可读。请不要假定深度只取少数固定值，或现任误差只取固定档位。

## 必须交付

`METHOD.md`：数学对象与变量；观测如何编码、几何如何解码；保留/近似/丢弃哪些信息；为什么预计更好；适用范围；方法是等价改写/近似/模型改变/新信息中的哪类（可多选）；开发运行成本。`method.py` 与可执行测试。可选一个明确的结构消融开关，并在开发结束前冻结。不凭方法名称宣称原创；此轮测试自主构造与效用，不做新颖性认证。

主要评价：全部修订的坐标MSE/MAE、相对identity改善/不变/恶化比例、正确现任损伤、实际运行秒数。两截面完整报告；低误差但明显伤害正确现任不能合并成一个“全面获胜”。预先定义的合成机制分层只在评分时使用。
