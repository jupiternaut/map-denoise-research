# Scope

This is a new bounded computational metaresearch experiment on host `liekkas`.
Do not modify earlier point-cloud or Hermes experiments. Do not run paid APIs,
install dependencies, publish to GitHub, or consume GPU resources.

The premise P=NP motivates a **finite exact-search surrogate**. Exhaustive search
does not implement a polynomial SAT algorithm and cannot test or prove P=NP.
Do not describe results as autonomous LLM learning or real-world realtime control.

Learners receive only training inputs/labels and a public grammar. Evaluators alone
use target labels at unobserved inputs. Planners may use the public possible-world
catalog and goal function, never the identity of the actual deployment world.
An empty consistent set means support failure, not a successful certificate.

All new code edits use apply_patch. Results may be written by experiment scripts.
Keep protocol changes explicit. Record raw rows, seeds, test commands and failures.
No thresholds or populations may be revised after results to manufacture a win.
