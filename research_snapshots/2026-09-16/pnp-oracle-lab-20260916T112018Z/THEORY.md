# Conditional theory and what this lab actually tests

## 1. Conditional learning theorem

Let programs have fixed padded L-bit encodings with polynomial-time validity and
evaluation. Let labels be generated by a program in that class, and let examples
be iid from the same distribution D used for testing. If P=NP, consistency can be
decided in polynomial time and a consistent encoding found by prefix search.
For m >= (L ln2 + ln(1/delta))/epsilon, a union bound over at most 2^L programs gives
P[R_D(h)>epsilon] <= 2^L exp(-m epsilon) <= delta for any consistent learner.

Polynomial-size boolean circuits are one eligible class; arbitrary unbounded
programs are not. This is a consequence of established learning/complexity theory,
not a novel theorem claimed by this experiment. Here we enumerate a MUCH SMALLER
formula class exactly, so we do not verify asymptotic polynomial runtime or PAC
coverage experimentally. Our semantic catalog is finite and honestly disclosed.

## 2. Conditional feedback synthesis theorem

For a nonempty version space C with polynomially bounded model encodings and
polynomially decidable membership, polynomial-size strategy programs, polynomial
finite horizon and polynomially checkable simulated trajectories, the question
exists pi for all h in C: V(pi,h)=1 is in Sigma_2^P. Under P=NP, first deciding
whether a policy has an NP-certifiable counterexample becomes polynomial, and
then existential policy synthesis becomes polynomial as well. Prefix search
extracts a bounded policy. Existence of a feasible policy remains a separate
condition; a vacuous empty C is not a success certificate.

This lab uses exact enumeration/DP over 16 worlds and known deterministic bit
queries. Optimal Bayes terminal classification is computed by finite summation,
not by assuming P=NP makes arbitrary #P counting easy. A risk-zero policy is also
a robust certificate over this particular finite support; positive Bayes success
alone is not worst-case safety.

## 3. Composition and real-time limits

A good predictor under D need not be good under a policy-induced distribution.
Experiment C controls the evaluation world distribution and compares learned-goal
planning with a true-goal oracle. It does not assume prediction quality implies
physical safety or safe exploration. Limited-support training is an intentional
information stress, not an iid generalization test.

Hard realtime additionally requires a worst-case observation/update/solve/action
latency bound below a specified deadline. Our query cost is a simulated resource;
measured Python wall time is not an operating-system realtime certificate.

## 4. Information obstruction

If two feasible worlds have the same observations under every available sensing
action but require opposite final actions, no deterministic policy succeeds in
both. A uniform two-world prior limits success to 1/2 even with unlimited compute.
The missing-sensor diagnostic tests this finite analogue directly.

## 5. Scope of the surrogate

Finite exact search removes optimization error only within the declared grammar,
world support and policy class. It does NOT remove representation error, ignorance,
calibration assumptions, simulator mismatch, or external latency. It does not prove
P=NP, implement its hypothetical polynomial algorithm, or demonstrate a language
model updating its own weights. The frozen model API need not be invoked at all.
