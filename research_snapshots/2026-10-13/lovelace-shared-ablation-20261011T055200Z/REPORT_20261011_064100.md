# 共同材料解释的贡献：完整预算六臂消融报告

日期：2026-10-11；主机：liekkas；批次：lovelace-shared-ablation-20261011T055200Z。
状态：六臂执行完成，独立机械核验 PASS，配对分析完成。本报告不改变真实部署默认，也不发布 GitHub/GitBook。

## 1. 原始目标与本轮判断

长期目标是**保留有效几何，修复不足**。本轮检验：此前的修复收益究竟来自共享材料解释，还是逐通道对照被较小搜索预算限制；再把跨像素、跨视图和灰度通道相等三种约束拆开。

**结论：在这批冻结合成观测内，完整搜索没有消除共享方法的优势。跨像素共享是关键约束，跨视图共享提供进一步收益；放开灰度相等后仍保留多数平均收益。**

最佳预定臂 global_gray511 修复 115/432 个偏移初态，MAE 从 1.500000 降至 1.164813 模型 mm（降低 22.35%），MSE 降低 33.46%。54 个正确初态全部保留；全部方法在本批均未出现恶化。

这不是新增真实扫描确认。所有臂使用上轮完全相同的 54 组照片观测，不把“又跑一批代码”计作新数据证据。

## 2. 固定什么，改变什么

### 2.1 数据与单位

- 6 个模板 × 3 个深度 × 3 个噪声种子，共 54 组观测。
- 每组 9 个初态：正确位置和 ±0.25、±0.75、±2、±3 模型 mm，合计 486 个初态。
- 主终点只统计 432 个偏移初态；54 个正确初态单独检验保留。
- 9 组不可辨识负控包含 72 个偏移初态；其余 45 组观测包含 360 个偏移初态。
- 这里的 mm 是合成模型坐标单位，不是激光参考点云上的实测毫米收益。432 个初态也不是 432 个独立真实场景。

照片、几何外包内核、公开半径 1/5、观测误差界 1/100、深度域 [540,660]、停止容差 15/32 和旧动作选择器均固定。none/partial/full 三种整场景解释分别求解后取并，不允许各像素任意拼接遮挡解释。全部动作先落盘，之后才由评价端读取真值评分。

### 2.2 六臂

| 方法 | 改变的材料一致性关系 | 材料变量数 |
|---|---|---:|
| KEEP | 不移动初态 | 不适用 |
| channel511 | 旧逐通道必要外包 | 逐通道松弛，不等同于一个统一材料估计 |
| global_gray511 | 所有像素、视图、通道共享三种灰度材料 | 3 |
| pixel_gray511 | 每个像素独立三种灰度；只保留同像素通道交集 | 432 |
| view_gray511 | 每视图独立三种灰度；视图内像素共享 | 9 |
| global_rgb511 | 三种材料各有独立 RGB；跨像素、视图仍共享 | 9 |

变量数仅指材料未知量，不是整个潜变量空间维数。删除相等约束也增加了自由度；本实验没有把“共享关系”与“参数个数”另行独立分解。

每个整场景分支预算为 511 个深度盒，足以遍历给定容差下的最多 256 叶完整二分树。材料必要约束仍只传播 8 轮，未证明不可行的盒保留。**深度树完整不等于联合可行性已精确求尽。**

## 3. 主终点：共同解释明显改善修复

主表分母均为 432 个偏移初态。改善/同分/恶化按最终坐标误差相对 KEEP 计算。

| 方法 | 改善 / 同分 / 恶化 | MAE（模型 mm） | MAE 降幅 | MSE（模型 mm²） | MSE 降幅 |
|---|---|---:|---:|---:|---:|
| KEEP | 0 / 432 / 0 | 1.500000 | 0 | 3.406250 | 0 |
| channel511 | 0 / 432 / 0 | 1.500000 | 0 | 3.406250 | 0 |
| global_gray511 | **115 / 317 / 0** | **1.164813** | **22.35%** | **2.266513** | **33.46%** |
| pixel_gray511 | 0 / 432 / 0 | 1.500000 | 0 | 3.406250 | 0 |
| view_gray511 | 52 / 380 / 0 | 1.397642 | 6.82% | 2.970084 | 12.80% |
| global_rgb511 | 94 / 338 / 0 | 1.239593 | 17.36% | 2.505790 | 26.44% |

global_gray511 的改善率为 26.62%，未改善率为 73.38%。global_rgb511 改善率 21.76%，view_gray511 为 12.04%。

各臂均达到：

- 54/54 真实观测深度仍在保留外包内；
- 54/54 正确初态 KEEP；
- 72/72 不可辨识负控偏移初态 KEEP；
- 恶化 0，预算未决叶 0。

“未改善”仍是主要部分，不能把零损伤写成已经修好了所有错误；负控也没有因算法更复杂而凭空获得信息。

## 4. C1：更完整的预算没有抹掉上轮收益

只读比较上轮 255 盒结果与本轮对应 511 盒结果：

| 同输入比较 | 偏移初态 | 输出完全相同 | MAE / MSE 改变量 |
|---|---:|---:|---:|
| channelwise_union255 → channel511 | 432 | 432 | 0 / 0 |
| shared_union255 → global_gray511 | 432 | 432 | 0 / 0 |

上轮 channel 有 21800 个预算未决叶，共享臂有 2304 个；本轮两者均为 0，但终点动作未改变。因此可以关闭这一具体解释：

> 上轮共享法领先，仅仅因为逐通道对照被 255 盒预算截断。

更严格的表述是：**在固定容差、固定外包和固定动作选择器下，完整深度树挑战未消除差距。** 这不是整个连续联合模型的全局最优证书，也不排除另一种更强的可行性求解器。

原始比较见 outputs/analysis-v1/BUDGET.json。

## 5. C2：三种共享关系的贡献不同

### 5.1 取消跨像素共享，终点修复归零

pixel_gray511 仍保留同一个像素内 RGB 的相等条件，却与 channel511 一样，432 个偏移初态全部 KEEP。相比之下，global_gray511 修复 115 个。

这支持：收益不只是同像素三个通道的交集，**不同像素必须由同一材料解释**才产生当前有效约束。

### 5.2 保留视图内共享，只能恢复部分收益

view_gray511 修复 52 个，MAE 降低 6.82%；再要求跨视图共享的 global_gray511 修复 115 个，MAE 降低 22.35%。

逐初态配对：global_gray511 相对 view_gray511 有 **91 个更好、341 个同分、0 个更差**。115−52 只是修复数量差，不能替代这项配对比较。

### 5.3 放开灰度相等，仍有修复，但不是逐实例全序

global_rgb511 修复 94 个，MAE 降低 17.36%。按平均 MAE 改善量计算，保留了 global_gray511 改善量的 77.69%；这是算术比例，不是因果贡献分摊。

gray 相对 RGB 的实际配对为 **39 个更好、389 个同分、4 个更差**。所以 gray 的平均终点更好，不代表它在每个初态都占优。材料可行族的包含关系不能直接推出有限传播、区间并及动作选择后的误差逐实例单调。

本批照片仍来自原来的灰度材料生成族。RGB 臂是在同一灰度观测上放宽假设，**不是已经检验了真实彩色材料的迁移**。

配对明细见 outputs/analysis-v1/PAIRED.json。

## 7. 为什么共同解释有用

令 p 指一个视图中的像素，材料暗度 d_j=1−c_j∈[0,1]，真实面积权重 a_pj 的外包为 L_pj≤a_pj≤U_pj。由于暗度非负，

L_p·d ≤ a_p·d ≤ U_p·d。

灰度材料要求三个通道共用同一 d，所以每像素得到两条必要半空间：

L_p·d ≤ min_k(1−y_pk+ε)，
U_p·d ≥ max_k(1−y_pk−ε)。

不同方法改变的是哪些像素必须共用这个 d：

- 每像素独立解释，容易允许相互不一致的材料答案；
- 一个视图内共享，可以排除一部分不一致；
- 跨视图仍共享，必须找到能同时解释更多观测的一套材料；
- RGB 放松通道相等，但保留跨像素、跨视图共享，因此仍有明显收益。

逻辑核心是 **“每个观测各自存在一个解释”不等于“存在一个共同解释适用于全部观测”**。本轮把这一关系转成必要约束传播，并测得它进入了几何终点，而不只是降低照片残差。

这一解释保留了当前方法的资产：物理成像关系产生约束，约束限制可接受的几何，旧动作器据此修正。不需要本轮额外训练一个收益预测器，也没有增加供算法挑选的真值标签。

当前共享族是预定的三材料合成模型。其适用边界，尤其跨视图曝光、光照和反射变化，仍需检验。

## 9. 对整体课题的推进与下一步

本轮将“共享材料可能有效”收紧为一项可复算机制结论：**完整搜索下，共同解释仍提高几何修复；跨像素共享与跨视图共享具有不同的实测作用。** 这比继续增加候选和评分器更接近可用于算法设计的规律。

下一项首选是**有公开误差界的跨视图外观变化压力测试**：冻结几何，分别加入视图曝光/偏置以及真实彩色材料；比较硬共享、视图独立与带界的共同材料解释。要观察真实深度覆盖、错误移动、修复率和最终 MAE，而不只看外包宽度。

若有界模型能在共享失配时恢复覆盖并保留收益，可把“同一材料”升级为“同一材料经过受限观测变换”的结构；若始终没有增量，则不继续堆共享复杂度。实际彩色生成与外观变化需要分开，不能用放松 RGB 的本轮结果替代。

另将精确半空间可行性、8 轮/行序敏感性与灰度对 RGB 的 4 个反向初态列为有序验证项。后续规划只归档，**本轮未自动运行下一批**。

本轮没有真实点云净收益的新证据，未修改部署默认、未上传 GitHub/GitBook；对该合成机制的支持已经完成，不需要再用同一数据反复复制正结果。
