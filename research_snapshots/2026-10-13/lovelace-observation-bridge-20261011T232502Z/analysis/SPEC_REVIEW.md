## 数学识别及有效结论

设理想预测 x 属于 [0,1]，R=x+e，|e|≤epsilon，P 为区间投影，|b|≤beta。则 |P(R)−x|≤|R−x|≤epsilon，且 |R+b−x|≤epsilon+beta=delta、|P(R+b)−x|≤delta。因此本批每个单元都可沿用对应公开宽度的必要误差行；RBdelta 允许越界并不使其诊断失效。这个论证依赖原几何/材料模型的预测在 [0,1]，不重新证明历史几何核。

生成顺序必须为先取未裁剪 R、再加 b、最后按单元决定是否裁剪。`P(R)+b` 或 `P(P(R)+b)` 都是另一个干预。对裁剪图直接减实际 b 并沿用旧行也不在本批内。

以相同初态 i 的预先指定终点为 F_i(U)，协议允许以下精确配对解释：

| 对比 | 可声称的改变 |
|---|---|
| C0epsilon−R0epsilon | 在无附加偏差、窄界条件下改变裁剪处理 |
| R0delta−R0epsilon | 同一原始图只放宽公开误差界 |
| C0delta−C0epsilon | 同一裁剪图只放宽公开误差界 |
| RBdelta−R0delta | 固定宽界、未裁剪条件下加入固定 b 模式 |
| CBdelta−C0delta | 固定宽界、裁剪条件下加入固定 b 模式 |
| CBdelta−RBdelta | 固定 b 和宽界下改变裁剪处理 |
| C0delta−R0delta | 无附加偏差、宽界下改变裁剪处理 |
| CBdelta4/16−CBdelta | 同一图、同一界、同一其余配置下改变传播轮数 |

有限设计中的裁剪×宽界交互为 `(F(C0delta)−F(R0delta))−(F(C0epsilon)−F(R0epsilon))`；宽界下裁剪×偏差交互为 `(F(CBdelta)−F(RBdelta))−(F(C0delta)−F(R0delta))`。后一式也等于两种裁剪条件下的偏差效应之差。应固定方向和单位，逐初态配对后汇总；MAE/MSE 的差与改善人数的差不能混成同一个指标。

本设计不是完整三因素全因子实验：没有有偏差的窄界单元，不能估计完整的界×偏差或三阶交互。它也不需要这些通常不满足窄界合同的单元来回答已登记问题。

允许沿某条已声明路径作恒等式，例如 `F(CBdelta)−F(R0epsilon) = [F(C0epsilon)−F(R0epsilon)] + [F(C0delta)−F(C0epsilon)] + [F(CBdelta)−F(C0delta)]`。这只是特定路径的端点差分解；换路径可能得到不同的分量，不能称为三个互相独立、普遍可加的贡献百分比。115 与 32 的人数差也不能替代逐初态得失转移，因为它不显示是否为同一批初态。

若裁剪后某些动作更好，只能报告此算法在这些配对输入上的终点改变。裁剪为确定性投影，不能由这样的终点改善宣称它创造了物理观测信息；集合松弛、有限计算和固定 selector 与终点误差是不同层次。类似地，界变宽后的某个实例误差不必变差，合法方法之间不要求逐例误差排序。

若 4、8、16 轮的外包、保留集合和动作都相同，只能称“本 54 个固定观测在 4/8/16 轮范围内对这些输出稳定”。不能称已达传播不动点、精确 LP、共同几何可行或剩余 KEEP 已不可辨识。若只有平均 MAE 相同而个别动作/集合不同，必须分别披露，不能写“所有结果一致”。若输出改变，则显示本局部范围的计算敏感性，不等于证明新物理信息或一个新求解算法。
