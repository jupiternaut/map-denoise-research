# 非空深度集合上的修正收益与三视图机制装置

本目录实现两个可分开检查的产物：有限闭区间并集上的严格收益判别 kernel，以及二维截面、1D RGB 图像的独立机制示例。后者不是本次真实回放的完整 kernel，不能称作真实端到端验证。所有数值使用任意但统一的场景长度单位；收益单位为该单位的平方，不是毫米平方的实测效果。

## 1. 同射线中点判别及证明

设参考相机某一固定射线、固定真实目标物理层的深度为 z。旧值为 a、待修正值为 b，目标损失是深度平方误差。收益为

Δ(z) = (a-z)² − (b-z)² = (a-b)(a+b-2z) = 2(b-a)(z-m)，其中 m=(a+b)/2。

令 S=∪ᵢ[lᵢ,uᵢ] 为非空有限个有界闭区间的并。记 L=minᵢ lᵢ、U=maxᵢ uᵢ。Δ 是 z 的仿射函数，所以其在每一闭区间上的最小值和最大值取于端点；再对各段取极值，得到

infₛ Δ = min{Δ(L), Δ(U)}，supₛ Δ = max{Δ(L), Δ(U)}。

因此，若 b>a，所有可行目标深度都严格获益，当且仅当 L>m；若 b<a，当且仅当 U<m。严格变差对应另一侧。跨越中点的集合不能确定严格改进方向，即使中点本身不在非凸集合内。如果集合触及中点但不越过，只能证明弱不变差，不能证明严格改善。a=b 时 Δ 恒为零，任何非空集合都不能证明严格改进。

这里“当且仅当”针对非空、有限闭区间并；开放集合可能逐点严格大于零而下确界为零，不能直接套用严格正下界的等价式。集合可以无序、相互重叠或非凸，kernel 不要求先合并。由于损失差仿射，凸包与原集合的极值相同，但内部间隙仍有观测、身份和覆盖意义，结果文件保留各个分量。

空集表示观测矛盾或无支持，不能把“对空集中所有 z 都改进”当作接受证据。`gain_bounds(a,b,[])` 返回 `None`，`strictly_improves(None)` 为假。只有非空且下界严格大于 `gain_floor=0` 才采用 b。实际深度必须属于 S，结论才对实际目标成立。

## 2. 冻结三维候选的仿射推广

真实候选可能不在参考射线上，不能擅自移动候选到射线。对于任意冻结的世界坐标 a,b，相机中心 C、非零参考射线方向 r，以及目标点 T(z)=C+zr，三维平方距离收益为

Δ_world(z) = ||a-C-zr||² − ||b-C-zr||²
            = ||a-C||² − ||b-C||² − 2z r·(a-b)
            = κ + s z。

二次项 z²||r||² 相消，所以仍用 S 的最左、最右端点获得精确极值。`gain_bounds_world(a,b,C,r,intervals)` 实现此式；r 不必归一化。当 z 是相机 optical-Z 时，可用相应未单位化世界射线，以保持 z 的定义。若 s≠0，分界深度为 −κ/s；若 s=0，收益恒定，可能恒正、恒负或恒零，不能使用普通深度中点规则。两候选都在同一射线上时，Δ_world=||r||²Δ_depth，符号与中点规则一致。

该推广证明的是到同一个 T(z) 的欧氏平方距离，不是到激光顶点集合的最近距离，也不证明对应目标的物理层身份。最近激光顶点可能随候选变化，因此主实验的最近顶点指标必须单独评价。

`kernel.py` 用精确有理数计算所输入二进制 float 所表示的数，再向外舍入返回界。这样不会因最终端点舍入把理论零收益误当严格正收益；不改变相机、对应、区间端点的物理覆盖不确定性。区间端点构造本身仍是普通数值几何，其误差没有被自动计入观测预算。非有限输入、反向区间、零方向向量会明确报错。

## 3. 先固定世界，再拍摄，再匹配，再决策

小协议在实现和首次渲染前写入 `PROTOCOL.json`，校验值为 `bb09e651d986015ad06d31bebba31f79aeadfec6d494e344ff676c9214d0b7e3`，另存 `PROTOCOL.sha256`。固定种子 11、23、47，四种场景全部报告；没有依结果修改阈值、图案、候选或种子。首次结果与随后数值运算加固记录在 `RUNLOG.md`。

相机位于 x=0、−0.6、0.7，光轴同向，焦距 180px，图宽 721px。固定参考像素 351，其射线斜率为 −0.05。真实目标预先固定为后表面上的点 (x,z)=(-0.3,6)。后表面 z=6，x∈[-10,10]；前表面 z=3，为有限、不透明的区间，普通场景 x∈[1.4,1.9]，遮挡场景 x∈[-0.09,0.35]。每条像素射线与这两个面求交，最近合法交点的世界纹理决定颜色，随后添加标准差 0.002 的传感器噪声。

每个面只有一份共享的世界 RGB 纹理，跨视图没有独立重画。`make_scene` 不接收 a,b；先把纹理和真实身份写入 `world_textures.npz`、`scene_before_render.json`，再渲染照片。匹配函数仅接收照片、固定参考像素和预注册匹配设置，不接收真实深度、表面身份或候选。观测保存并求哈希后才计算候选收益和事后真值诊断。

1D patch 半径为 3，共 7×3 个颜色样本，减均值后做 NCC；阈值统一为 0.78。参考—源两臂首先共享完全相同的、全图搜寻的全部参考匹配，不做 best-match、ratio-test 或按真值挑选。源—源匹配独立计算两个源图全部有效 patch 的 NCC 矩阵，同样保留所有 ≥0.78 的测得像素对。

对源相机中心 c，参考像素 u₀ 的候选目标深度 z 预测源像素为 u₀−fc/z。每个整数测得对应像素 v 产生约束 |v−u₀+fc/z|≤0.65px，解析反解并截入固定深度域 [2.5,7.5]。star 臂对全部参考—源匹配对取几何区间交集再求并；common_track 臂额外要求该同一源像素对出现在独立测得的源—源匹配集中。两臂复用同一批照片、参考对应、几何、NCC 阈值和像素预算。新增的是源—源观测，不是候选投影伪造的闭环。

“共同轨迹”在这里只是测得的光度与几何一致轨迹，不能自动等同于真实同一物理点。深度覆盖和表面身份只用于最终诊断，未用于删匹配。

## 4. 固定场景结果

全部 12 个场景实例均完成，13 个 kernel 测试通过。最终机制运行约 1.546 秒，CPU-only，BLAS/OMP 线程数 1。下表每行结果均在三个种子上出现；每个臂的完整数值见 `results/summary.csv` 与 `results/results.json`。

| 场景 | star 可行集合 | common_track 可行集合 | star / common_track 采用 b | 真目标被覆盖 | 采用后的真实收益 |
|---|---|---|---|---|---|
| 正例 | [2.9543,3.0472] ∪ [5.8199,6.1916] | [5.8199,6.1916] | 否 / 是 | 两者是 | 0 / +2.4 |
| 完全重复纹理 | 同正例 star，两段 | 同样两段 | 否 / 否 | 两者是 | 0 / 0 |
| 遮挡、错误源物理层 | [3.5344,3.6681] | 同样一段 | 是 / 是 | 两者否 | −4.2 / −4.2 |
| 相机共同尺度误差 | [3.2009,3.4054] | 同样一段 | 是 / 是 | 两者否 | −5.28 / −5.28 |

正例中，世界纹理预放三个图案 p、p+0.6v、p−0.6v，其中 v 与去均值 p 正交且等范数。三者是不同位置的实体纹理，不由候选生成。种子 11 的错误参考—源对应 NCC 为 0.8580、0.8603，均通过；两个错误源 patch 互相只有 0.4771，未通过源—源阈值。真对应三条边均约 0.9998。star 的收益下界为 −4.9097，新增观测后下界为 +1.9677，实际收益 +2.4。其机制是相似度阈值关系不传递，新增一条实际测得的边可排除某些歧义，并不是“第三视图必定正确”。

完全重复纹理把三个实体纹理都设为 p。错误源对也约 0.9996，于是新增边不能消除错误分量；保留歧义并放弃修正，是这里的正确结果。三个种子只改变图案和噪声，并不改变场景结构；它们不是随机真实场景总体上的统计验证。

遮挡场景真实后表面目标在第二个源相机中被前表面挡住。错误轨迹的源像素为 (381,316)：第一个对应实际命中后表面 x=0.1，第二个实际命中前表面 x=−1/30，两个物理层不同，但其纹理都等于 p。种子 11 三条 NCC 都约 0.9997；几何得到约 z=3.6 的虚假目标集合，错误地证明 a=4.4→b=3.4 的集合内正收益。真实目标仍为 z=6，所以实际收益 −4.2。这是“固定真实身份、真实不透明遮挡、相似纹理伪装身份”的反例，不是通过真值选错匹配制造出来的误差。

相机共同误差场景保持实际照片和真实三相机不变，但推理时把两个源相机基线均乘 0.55。真物理目标对应全部正确，图像闭环也一致，却被几何解释为 z≈3.3。对于真实 z=6，该错误相机几何产生 8.1px 和 9.45px 的参考—源投影偏差，远超预设 0.65px。于是错误地接受 a=4.4→b=3.2，真实收益 −5.28。

因此共同误差反例检验的是“假定预算漏掉系统误差”的失效；它不证明相关性本身会破坏可靠误差界。如果每个约束的预算确实覆盖全部误差，包括共同项，则取交集不需要概率独立性，也不会仅因共享偏差就丢掉真深度。本例预算是工程假设，不是置信区间或已校准覆盖率。

## 5. 结论范围与产物

成立的结论：在覆盖同一真实目标的非空集合上，仿射收益端点规则严格成立；独立源—源实测对应可能增加方向判别信息；重复纹理可能保留歧义；错层和未计入的共同几何误差可以令一致的约束给出错误修正。有限机制装置支持这些存在性例子，不估计自然场景频率，不证明真实工程的预算覆盖或普适无害。

没有声称：定理新颖性、真实候选和激光评价上的改进、真实匹配器与该机制装置相同、物理身份可以仅凭循环判定、空观测等价于遮挡、跨相机误差独立、对非相同目标层套用中点定理。
