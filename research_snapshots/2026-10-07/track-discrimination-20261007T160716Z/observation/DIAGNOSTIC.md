# 封存轨迹的事后匹配诊断

本诊断由集成结果提出问题后进行，属于事后实现诊断，不是盲评或新实验。只读取 REQUESTS 和 observation 中既有源码、配置、封存轨迹及原始 NCC 曲线，没有读取评价、候选、真值或最终结果；没有重新匹配照片、改阈值、修改封存文件或建立新的选择器臂。下列分数均来自原封存曲线，几何量用原 `extract.py` 函数只读复算。

结论：scan118/query5 和 scan122/query75 的每条 star 轨迹，在原始直接源—源曲线上都有非局部峰采样点满足原 NCC、像素、区间和四观测三角化条件。它们的空 cycle 包含明确的“局部峰代表 + 1.5 px 容差”造成的过度收缩，不能说原始源—源阈值证据本身排斥这些 star 轨迹。scan118/query95 两条 star 附近的原始采样 NCC 都低于 0.6；这里确实增加了该指定阈值下的图像相容性限制。scan122/query48 有直接局部峰通过全部检查，cycle 保留。

## 几何检查的确切边界

这里“通过原检查”严格指原封存源码规则。源码要求三角化 Z 位于完整公知域，但没有额外要求最小二乘三角化点的 Z 位于最后参考射线支撑区间；二者分别构造。例如 query5/star1 见证的三角化 Z=650.440209，略低于区间下界 650.5；query5/star2 为 657.553095，略高于区间上界 657.5；query75/star2 为 686.443957，略低于 686.5。以上没有隐去，也没有加入新的修正规则。

原因在于支撑区间约束的是固定参考像素的射线采样并加工程 padding，而联合最小二乘点允许非零参考重投影误差。这些检查不等价于证明某个统一三维物理点满足所有连续约束。本诊断没有把这些有限工程条件提升为严格物理可行性保证。

## 最小只读复算代码

以下示例复算 query5/star0 的非峰见证。改动 `scene_id, query_id, star_id, k` 即可按上表复算其余见证；代码不调用 extractor.main、不写结果，也不访问评价。使用 `PYTHONDONTWRITEBYTECODE=1` 防止导入写缓存。

```python
import json, runpy
import numpy as np
from pathlib import Path

root = Path('/srv/slam-research/grf/map-denoise/runs/track-discrimination-20261007T160716Z')
p = root / 'observation'
f = runpy.run_path(str(p / 'extract.py'))
tracks = json.loads((p / 'TRACKS.json').read_text())
scans = json.loads((p / 'SCANS.json').read_text())
requests = json.loads((root / 'REQUESTS.json').read_text())
scene_id, query_id, star_id, k = 118, 5, 0, 240
row = next(r for r in tracks['rows'] if (r['scene'], r['query']) == (scene_id, query_id))
raw = next(r for r in scans['rows'] if (r['scene'], r['query']) == (scene_id, query_id))
st = row['star_tracks'][star_id]
direct = next(s for s in row['direct_source_source_scans']
              if s['anchor_source1_node'] == st['source1_node'])
curve = next(s for s in raw['scans'] if s['id'] == 'direct-' + st['source1_node'])
component = next(c for c in direct['components']
                 if c['sample_index_range'][0] <= k <= c['sample_index_range'][1])
node = {'pixel_xy': curve['target_pixels_xy'][k],
        'component_interval_mm': component['padded_interval_mm']}
grid = np.asarray(curve['reference_depth_grid_mm'])
ref2 = np.asarray(next(s for s in raw['scans'] if s['id'] == 'ref-to-0061.png')['target_pixels_xy'])
obs = {'reprojection_tolerance_px': 1.5, 'interval_padding_mm': 1.0}
support = f['intersection'](st['intervals_mm'], f['node_ray_support'](node, ref2, grid, obs))
scene = requests['scenes'][str(scene_id)]
cams = [f['camera'](scene['cameras'][n]) for n in [scene['reference'], *scene['sources']]]
tri = f['triangulate']([*cams, cams[2]], [*st['pixels_xy'], node['pixel_xy']], cams[0])
distance = np.linalg.norm(np.asarray(st['pixels_xy'][2]) - node['pixel_xy'])
print({'ncc': curve['ncc'][k], 'pixel_distance': float(distance),
       'support': support, 'triangulation': tri,
       'passed': curve['ncc'][k] >= 0.6 and distance <= 1.5 and bool(support)
                 and f['geometry_ok'](tri, scene['depth_range_mm'], obs)})
```
