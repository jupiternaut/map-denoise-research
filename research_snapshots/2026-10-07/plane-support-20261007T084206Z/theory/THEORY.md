# 邻居平面到 optical-Z 区间与有限候选选择

适用范围：条件性数学界与 CPU 参考内核。本文不读取真实 GT、旧 evaluation 或误差标签，不宣称真实误差已知、校准、conformal 或统计置信覆盖。本轮的真实误差预算是可解释的假设；合成覆盖只验证满足假设的输入。

## 1. 坐标与测量模型

所有向量必须在同一个欧氏坐标系，长度单位一致（真实分支为 mm）。目标射线写作

`X(z) = C + z r`，其中 `z` 是参考相机的 optical Z。

在参考相机系，`C=0`，`r=K⁻¹[u,v,1] / (K⁻¹[u,v,1])₃`，因此 `r₃=1`，一般 `||r||≠1`。若用 world-to-camera 旋转 R，则世界射线是 `Rᵀr_camera`，仍不能归一化成单位射线，否则变量变成射程。世界法向也必须同步变换。公式与旧 `neighborhood_v2.py:plane_prediction` 的相机坐标约定一致。

帽号表示观测。邻居锚点为 `X_j`，相对锚点 `A=X_j-C`。真实单位法向 n 满足在一致朝向下 `angle(n,n̂)≤θ<π/2`；平面无朝向，整体翻转 n̂ 不改变计算，角预算按对应的同号真实法向理解。必须先把非零观测法向归一化；θ 不是原始法向各坐标的误差。

假设：

- `||A-Â||≤ε_A`，`||r-r̂||≤ε_r`。
- 真实目标表面点满足 `|n·(C+z*r-X_j)|≤κ`。
- `z*` 位于调用方给定的非负深度域。域不能由 GT 或待选候选结果反推。

ε_A 可直接约束相对量；若只有绝对界 `||X_j-X̂_j||≤ε_X` 与 `||C-Ĉ||≤ε_C`，安全但可能宽松的取法是 `ε_A=ε_X+ε_C`。不要求变量独立、零均值、随机、无偏或高斯，所有陈述逐个误差实现成立。相关性不会使这些上界失效；忽略相关性通常使上界更宽。

同一参考相机的共同刚体变换 `X' = QX+t, C'=QC+t, n'=Qn, r'=Qr` 保持所有点积、局部距离、深度与界不变。这种坐标重表达不是物理标定误差。本文的本地真实实现不因此声称能处理任意跨相机内外参误差。

## 2. 有限、非渐近的深度界

记

`d̂ = n̂·r̂`，`ẑ = (n̂·Â)/d̂`，`s = Â-ẑr̂`。

于是 `n̂·s=0`。这一步保留了同一法向同时出现在平面偏移与分母中的关联；不能先把两个法向扰动当独立随机误差。局部 `||s||` 是观测锚点与预测交点的距离，不是相机到邻点的深度。

### 2.1 弦长形式

若 `||n-n̂||≤η`（角预算可取 `η=2sin(θ/2)`），则

`γ_chord = |d̂| - η||r̂|| - ε_r`。

当 `γ_chord>0` 时，

`|z*-ẑ| ≤ [η||s|| + ε_A + |ẑ|ε_r + κ] / γ_chord`。

证明：令 `δA=A-Â`、`δr=r-r̂`、`e=n·(z*r-A)`，其中 `|e|≤κ`。精确恒等式为

`(z*-ẑ)n·r = (n-n̂)·s + n·(δA-ẑδr) + e`。

真实法向是单位向量，所以第二项上界为 `ε_A+|ẑ|ε_r`，无需再加 ηε_A 或 ηε_r 乘积。分母利用 `|n·r|≥|d̂|-η||r̂||-ε_r`。这是有限误差界，没有一阶线性化余项。

### 2.2 更紧的角度形式（主内核）

令 `r̂_perp=r̂-d̂n̂`。单位法向球冠几何给出

`γ_θ = |d̂|cosθ - ||r̂_perp||sinθ - ε_r`。

当 `γ_θ>0` 时，

`R_θ = [sinθ ||s|| + ε_A + |ẑ|ε_r + κ] / γ_θ`，

`I = [ẑ-R_θ, ẑ+R_θ] ∩ depth_domain` 包含 z*。

证明：按 d̂ 的符号对齐射线投影；球冠中 `sign(d̂)n·r̂` 的最小值为 `|d̂|cosθ-||r̂_perp||sinθ`（θ<π/2 且 nominal 投影为非负）。再减去 `|n·δr|≤ε_r`，正下界保证分母同号且远离零。因为 s 与 n̂ 正交，`|(n-n̂)·s|=|n·s|≤sinθ||s||`。代回前述恒等式即得。

如果可从共享误差源**独立推导**更紧的联合界 `||δA-ẑδr||≤ε_joint`，分子可直接以 ε_joint 替换 `ε_A+|ẑ|ε_r`；分母仍须保留其射线误差预算。不能因变量相关就假定它们相消，必须证明组合误差有界。

### 2.3 平行与数值边界

若 γ≤0，声明“这些预算无法给出有限深度界”；返回整个深度域并标记 uninformative。预算允许 `n·r=0` 时，某些允许输入没有交点或有任意大交点。不能把分母强行截断到某正数后当作保证，也不能把 uninformative 记录当成反对候选的投票。

若 γ>0 但 R 很大，界依然可能正确而没有分辨力。按输入几何和预先固定宽度规则弃用是允许的，但必须记录其数量，明确污染预算应用于哪个集合。正深度域截断后为空则说明该观察不能同时满足假设与深度域；内核返回 empty。

实现使用 float64，并把最终端点向外移动一个浮点单位；它不是经过验证的区间算术库。`denominator_floor` 只会额外弃权，不能在 γ≤0 时制造有限保证。合成测试有明确数值容差。

## 3. 可解释误差预算与模型缺口

邻居锚点 `X̂_j=ẑ_j r̂_j` 在同一参考相机系构造时，如果 `|z_j-ẑ_j|≤ε_z`、`||r_j-r̂_j||≤ε_rj`，则

`ε_A ≤ ε_z||r̂_j|| + (|ẑ_j|+ε_z)ε_rj`。

这里的乘积项不能漏掉。常规 pinhole K 的末行为 `[0,0,1]`，若像素误差是 L2 半径 p，`ε_rj≤||K⁻¹[:,0:2]||₂ p`。若每个像素坐标都可偏移 ±p，则 L2 半径是 `sqrt(2)p`。这仅处理指定的像素不确定性；K 自身误差需要另外的界。旋转角误差 α 与相机系射线误差 ε_q 可给世界射线界 `ε_r≤ε_q+2sin(α/2)||q̂||`。

本轮可解释的示例预算为深度 ε_z=1mm、法向 θ=2°、像素 L2 半径 p=0.25px、κ=0.25mm；由主实验协议冻结。它们全是 **ASSUMED / 未校准**，不是从真实 GT 得到的保证，也不在本文件优化。

κ 的角色是正确表面的模型偏差。若邻点附近曲面在真实切平面上能写为图 `h(u)`、`h(0)=0`、`∇h(0)=0`，且连接区间上 `||∇²h||₂≤H`，那么积分 Taylor 公式给 `|h(u)|≤H||u||²/2`，因此可在已知 `||u||≤ℓ` 时用 `κ=Hℓ²/2`。这是图 Hessian 的条件，不可无条件把主曲率数值直接当作 H。用错误深度推导 ℓ 再宣称独立保证会形成循环；需要先验域或单独证明的距离界。

跨面/遮挡邻居通常不存在这种小 κ：把它们计为污染，或明确放宽 κ 并承认失去分辨力。大多数邻居来自同一错误层时，任何小污染预算失效。同源深度或标定偏差可以同时推偏全部区间；重复记录不构成独立证据。非渐近界允许相关，但前提仍是每个预算真实覆盖相应误差。

## 4. 有限候选的条件可辨识性：从几何推导分数

令固定候选为 `{z_1,…,z_K}`。先假设池内至少有一个候选 `z_c` 满足 `|z_c-z*|≤ρ`。如果所有候选都偏离真值，则邻域支持不可能创造正确候选。

在 m 个保留区间中至多 b 个不包含 z*。定义展开区间 `J_j=I_j+[-ρ,ρ]` 和成员支持 `S_k=Σ1[z_k∈J_j]`。这不是假设正确候选分高：由每个好区间包含 z* **推导** `S_c≥m-b`。

因此，若恰有一个候选满足 `S_k≥m-b`，该候选必在真实深度的 ρ 邻域内；若多个满足则弃权。这里仍需要池覆盖与至多 b 个坏区间两个不可从分数自身验证的假设。

更先验的排除条件：设 `w_j=diam(I_j)`。对任一竞争候选 k，若

`T_ck = #{j: |z_c-z_k| > w_j+2ρ} > 2b`，

那么 `S_c-S_k≥T_ck-2b>0`，且 `S_k<m-b`，唯一阈值规则选 c。

证明：T_ck 个窄区间中的每个好区间必支持 c、不能同时支持 k；最多 b 个坏区间损失这些排除，另最多 b 个坏票可偏向 k。由此直接从区间宽度、候选间隔与污染数量推出优势，未把分数优势本身当作假设。若所有候选对均满足 T>2b，这个充分条件不需要提前知道哪个候选正确。宽区间让所有候选获支持时，T=0，规则应弃权。

污染不能仅按原始总体比例搬到过滤后的集合：过滤会改变污染比例。`select_candidate` 使用保留集合的绝对 b。高复制邻居数量也可能让假设虚假乐观；若污染以块发生，应按块预算或严格折算总坏票。

## 5. 真实分支的 certain/possible 排序，及其有限含义

主实验使用固定候选与现任，不移动候选。对候选 k 的深度容差带 `B_k=[z_k-τ,z_k+τ]`，令 a_j 表示区间有限且满足预冻结宽度门。所有有效邻居总数为 N，弃用者 a_j=0，仍留在分母。定义

`L_k = (1/N)Σ a_j 1[I_j⊆B_k]`，

`U_k = (1/N)Σ a_j 1[I_j∩B_k≠∅]`。

对任何可能相关的区间内取值 `ξ_j∈I_j`，定义**活跃邻居**的潜在支持

`V_k(ξ)=(1/N)Σ a_j 1[ξ_j∈B_k]`。

逐项即有 `L_k≤V_k≤U_k`。因此可观测条件 `L_k>U_l+δ` 对任何符合区间的联合取值都保证 `V_k-V_l>δ`。不需要独立性，不需要统计抽样。若最多 b 个活跃区间未包含其潜在值，则保守地

`V_k-V_l ≥ L_k-U_l-2b/N`。

主实验 δ=0.05 的间隔若仅略大于 δ，要保证污染后仍为正，需 `b/N<0.025`；实际观测间隔 g 可抵御 `2b/N<g`。这不是从数据估计出的污染率。共同错误会使所有 ξ 偏向错误层，排序依旧稳健而选错。

这证明的是“在给定区间内任意实现下，活跃邻居的固定带支持排序不变”，**不证明候选接近 GT**，也不证明 U 上界所有弃用邻居的真实支持。某些候选间距小于 2τ 时仅保留 winner 周围的近邻集合解释；“距离小于 2τ”非传递，不能无说明地称为严格簇划分。

照片 NCC 门与最小 L、max_radius 等规则是额外可观测选择条件；没有另行建立的光度模型时，它们不增加数学真值保证，多个证据源也不自动独立。本核不冻结主实验超参数，不替主代理按真实结果选优。

## 6. 最小接口与验证

- `optical_ray(K, xy)`：固定 optical-Z 射线约定。
- `pixel_ray_error(K, pixel_error)`：像素 L2 预算转射线预算。
- `anchor_error_from_depth(z_j,r_j,ε_z,ε_rj)`：锚点预算含乘积项。
- `plane_depth_interval(anchor,normal,ray,normal_angle_rad=…,…)`：角度界；返回 status、low/high、center/radius、分母安全余量及对照 chord_radius。
- `support_scores(depths,intervals,tolerance=ρ)`：成员支持与候选对排除计数。
- `select_candidate(depths,intervals,max_bad=b,tolerance=ρ)`：唯一 `S≥m-b` 规则，不满足则弃权。
- `certain_possible_support(depths,intervals,tolerance=τ,max_radius=…,denominator=N)`：真实分支的可观测 L/U，不读取光度、候选身份或真实评价。

测试：`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 python3 theory/test_kernel.py`（在新根运行）。包括随机有界联合扰动、共同刚体变换不变性、严格近切线弃权、污染阈值、池缺失/共同偏差反例及 L/U 实现界。测试结果是条件性算法验证，不能外推为真实数据校准。
