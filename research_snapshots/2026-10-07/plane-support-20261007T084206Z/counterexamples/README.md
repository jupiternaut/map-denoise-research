# 固定候选上的平面射线支持：有限合成反例

目标主机：`liekkas`。本目录只读自身合成输入，未读取真实旧数据、真实 GT 或官方最终几何。所有源文件与协议先写入，随后按生成→选择封存→评价顺序执行。固定 seed 为 `20261007`，CPU、Python 标准库，无额外依赖。

## 结果及适用范围

本实验有 82 份观测、83 个合成世界，五种选择器各评价一次，共 415 行。多出的世界和另一个世界**共用同一份观测**，不是近似匹配。64 个同层有界场景中，全部有效区间覆盖真值，四种几何方法全部选择真候选。在条件成立且门控接受的场景中，门控没有错误接受。这只是构造验证；不将合成频次解释为真实数据错误率，不将已知环境预算解释为真实误差标定。

|构造|具体结果|改变算法设计的条件|
|---|---|---|
|同层有界扰动，64 个固定 seed 变体|median、10 mm 固定半径、区间投票、唯一阈值均 64/64 正确；照片均错选 +40 mm 候选|仅在同层及误差预算成立时，邻域可以排除照片别名；简单方法同样成功，不能归功于区间公式独有优势|

## 条件性推导：这里使用的简化模型

本构造使用精确相机中心 `o=0`、单位射线 `r=(0,0,1)`；平面采用单位、同号法向 `n` 和方程 `n·X=d`。观测为 `n_hat,d_hat`，满足

```
||n - n_hat|| <= eps_n,
|d - d_hat| <= eps_d,
b_hat = n_hat · r,
t_hat = d_hat / b_hat.
```

如果 `|b_hat| > eps_n`，真平面与目标射线相交深度 `t` 满足

```
|t - t_hat|
  = |(d - d_hat) - t_hat (n - n_hat)·r| / |n·r|
 <= (eps_d + |t_hat| eps_n) / (|b_hat| - eps_n) = R.
```

所以采用 `[t_hat-R, t_hat+R]`。如果分母裕量非正，仅返回无信息的全深度区间。它对任何候选都给“可能支持”，因此不提供区分。这里没有声称该保守球界最紧；`theory/` 的 anchor/角度误差模型可给另一种界，不能把两种误差参数混用。

**候选选择条件。** 有 N 个支持区间，至多 K 个坏支持；所有好支持覆盖目标真深度 `t*`；固定候选池包含**精确的** `t*`。则真候选至少得到 `N-K` 票。若唯一一个候选达到这个阈值，它必为真候选。这不要求好支持相互独立，但要求坏支持数量的上界真的成立。若池中只有 `rho` 近似真候选，应先把区间扩展 `rho` 并重新论证，只声明“覆盖真深度”不够保证近似候选被覆盖；本脚本没有偷换为该更强命题。

这些是充分条件：有多个达标候选不代表所有选择必错，而是这个证据不足以证明唯一选择；没有候选达标也不允许任意阈值降低后继续声称同一保证。

## 违反假设和无法识别的情形

跨层例子中，每个邻居自身平面都测得准确，但污染平面并不属于目标层，因此其区间无需覆盖目标真深度。`conditions.csv` 以评价真值计算真实坏支持数，仅用于解释失效原因；选择器从未使用这个计数。唯一阈值固定声明 `K=2`，从未按结果改变。

共同偏移例子中，9 个观测法向都是 `(0,0,1)`，偏移都是 `2.04`，预算是 `eps_n=.0005, eps_d=.001`。投影中心为 2.04 m，区间半宽约 2.021 mm，因此错误候选全票获胜。在目标真深度 2.00 m 的世界，实际偏移误差 40 mm 超预算；这揭示观测内部不能确认预算成立。`source_group` 也明确记录这些观测具有共同误差来源，但选择器不赋予来源任何真实性保证。

同一观测对象 `common_shift_shared` 同时关联真值 2.00 m 与 2.04 m 两个世界；所有照片分数、候选、邻居和预算完全相同。任何仅依赖该观测的确定性算法输出相同深度，因此不可能在两个世界都正确。任意连续深度估计的最坏绝对误差至少为 20 mm；在本固定候选池（没有中点 2.02 m）中，任一单次候选输出的最坏绝对误差至少为 40 mm。随机选择不能产生缺失的信息；其风险需按期望等另行定义，本实验不以单次候选的 40 mm 界宣称随机期望风险界。

这组双世界允许一个世界违反误差预算，另一个成立，说明**观测不能自证预算**；它不反驳在预算与污染条件已由外部保证时的条件性定理。

## 重复纹理照片偏好如何生成

使用一维连续、可直接重算的光度残差。周期为 2 px，`fB=204 px·m`，真深度 2.00 m 对应视差 102 px，错误深度 2.04 m 对应视差 100 px，正好相差一个周期。65 个采样点 `x=(i-32)/8` 上，定义

```
target(x) = cos(pi*x) + .03*cos(2*pi*x/17),
source(u) = cos(pi*(u+102)) + .03*cos(2*pi*(u+100)/17),
loss(z) = mean_x [target(x) - source(x-204/z)]^2.
```

每幅图像相对纯周期纹理的结构扰动幅度不超过 .03；扰动恰在错误别名处对齐。因此错误候选 2.04 m 的损失约 `1.77e-31`，真候选 2.00 m 为 `2.269e-4`。这是预先指定的机制反例，没有基于评价搜索 seed。它不是完整光栅化渲染器，也不是相机真实噪声频率模型。

在同观测双世界中，纯周期纹理对 100 px 和 102 px 平移完全一样，同一结构扰动图像在两个世界都可作为幅度有界的观测扰动；所以照片输入也不提供区分信息。

## 重算与工件

在本目录运行：

```bash
python3 generate.py
python3 select.py
python3 evaluate.py
```

三个步骤全部 CPU，小于一秒的有限数值构造。`generate.py` 独立输出 `observations.json` 和 `evaluation_truth.json`；`select.py` 只读协议和观测，其决策依赖候选深度/照片损失、观测平面/预算及固定 K；场景名称和参数仅复制到报告。选择结束生成 `decision_seal.json`，记录观测、协议、选择器源码、决策 SHA-256。`evaluate.py` 先核对封存哈希，再读合成真值并评价。反例阶段没有读真实数据目录。

哈希证明的是封存文件与当前文件的一致性，不单独证明预注册时间顺序或操作系统访问隔离；本次工具执行记录支持生成→选择→评价的顺序，独立源码审查支持选择器未读取真值。协议字段 `locked_before_generation_and_evaluation` 与 `truth_files_read: []` 本身仍是声明。全部场景共用刻意构造的光度别名，不能把 82 个场景的照片失败次数当作独立、多样或有代表性的基准样本。

|文件|用途|
|---|---|
|`PROTOCOL.json`|生成与评价之前固定的 seed、预算、候选、阈值、拒绝规则|
|`generate.py`, `select.py`, `evaluate.py`|独立生成、选择、评价实现|
|`observations.json`, `evaluation_truth.json`|观测与仅评价使用的合成真值|
|`generation_manifest.json`, `decision_seal.json`|输入及源码身份、封存结果|
|`results.csv`|415 行完整方法决策及误差|
|`conditions.csv`|83 行理论假设是否成立、区间宽度、达标候选|
|`neighbor_diagnostics.csv`|747 行单邻居真实误差/预算、目标覆盖、平面同层性|
|`aggregate.csv`, `summary.json`|机器可读聚合与完整条件说明|
|`REVIEW.md`|独立只读重算与边界审查记录|

算法设计上，先区分“界无效”和“界有效但不能区分”。跨层与共同偏移需要额外同层/误差来源约束；区间过宽需要候选排除或确定/可能支持排序条件，无法用提高票数解决。来源去重能避免重复证据制造票数，但不能单独恢复绝对真值。这里没有发现区间投票普遍优于固定半径或中位数；宽预算反例明确给出相反结果。
