# 官方 MVS 能否补齐严重错误位置的候选

日期：2026-10-01（Asia/Shanghai）；主机 liekkas。

## 主张与对照

原目标是保留有效几何、修复错误几何。本轮只检验：修复相机接口后，成熟 MVS 是否提供比现有 CPU 平面扫描更好的几何，尤其是现有候选全部失效的位置。

这不是算法创新或跨场景确认：scan24/37 均为旧开发场景。旧恢复器不重训。若成熟基线足够好，优先保留其能力，而不再重复构造相同模块。

## 固定条件

- 4 ROI ×128 原查询位置，共512，来自旧 QUERY_MANIFEST；不按算法有效性或 GT 筛查询。
- 每场景 reference 0022 + Q=0016,0035,0017,0007，半分辨率777×581。图像是旧 half_gray 的逐字节灰度结果，另存 PNG 供 COLMAP 使用。
- 相机 R/C 与修复接口相同，单位 mm。数组整数中心转 COLMAP 角点制需 +0.5 像素；半分辨率 COLMAP 主点(388.5,290.5)。不重新估计相机。
- 不载入历史 SfM 3D 点，不用 GT 调候选。深度范围来自上轮 Q-only 匹配。
- 先完成相机/图像/深度回投单元测试，再运行官方 CUDA PatchMatch。

## 系统与指标

1. CPU plane sweep（修正相机后的现有输入）。
2. 官方 COLMAP photometric，参考图与4Q，同 reference depth interval；默认 PatchMatch 算法与过滤参数。
3. 官方 COLMAP geometric-consistency（若支持多图深度条件）：明确记录每图深度范围及与主臂差异，不隐藏额外范围。比较过滤输出；未过滤输出仅诊断。
4. COLMAP 有效时采用，否则保留 CPU 的固定回退，用于避免只在易点上比较。
5. 旧 KEEP/A/B 池和加入 COLMAP 后的同池 oracle 仅为候选能力诊断；不宣称可部署成绩。

主终点：四 ROI 等权点到固定激光参照 MSE（mm²）、512 查询覆盖率；共同有效点的成对误差单列。记录 MAE、中位数、1mm正确且有效数量/512、>5mm数量。原75个旧池全部>5mm的位置补齐多少，只在预测封存后计算。

不删离群点，不用新输出改变评价参照，不以新方法的有效子集替代原分母。缺失无法定义MSE；分别给条件误差与覆盖，固定回退在原497个有效CPU查询上比较。新覆盖的15个位置另报，不混入原497点的增益。

通过条件：至少两个场景在固定回退后的等权MSE下降，且旧池难点中有新候选≤5mm；同时报告原来≤1mm点被破坏的数量。若仅筛掉难点而误差下降，不算补齐成功。阈值是本轮验收建议而非既有理论界。

## 顺序与预算

M0：安装独立环境、相机投影/灰度字节/固定像素测试。
M1：单设备、单任务官方MVS，先scan24再scan37；已有训练任务运行则等待，不抢占、不杀其它程序。预计每种子数分钟至几十分钟，内存8GB，图像固定半分辨率。
M2：优先3个显式seed（若CUDA实际不支持seed，诚实记作重复而不是伪造独立seed）。全部输出封存后统一评分。
M3：独立复算、结果图、报告与下一步决策。不新增学习器或调度器。
