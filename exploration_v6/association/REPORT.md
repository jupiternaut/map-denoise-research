# V6 B：保守关联纯化改变了共享斜率的得失

2026-09-12，liekkas。运行目录：[association-v6-bgcq8zff](/srv/slam-research/grf/map-denoise/runs/multiscan-pilot-v1/association-v6-bgcq8zff)。

## 结论

在**不扩大原组观测范围**的 GT 仅拆分诊断中，全组共享斜率的表面位置表现由明显退化
转为相对独立斜率的改善。预声明的18个公开双层输入，oracle 共享对 oracle 独立的
表面 MAE、对应点 RMS 都是18胜0负；原关联下共享的对应点 RMS 则是18负。
这为“混合关联与共享约束存在有害交互”提供了比 V5 事后组构成更强的干预证据。

它**不是可部署方法或新确认**，也没有完整修复层距：oracle 共享对 oracle 独立的同 XY
间距误差为9胜9负。GT 拆组改变了参数数和每组信息量，部分独立拟合因此秩亏；
不能把收益全部归于标签正确，或声称共享斜率对真实复杂片区已有效。

## 设计与边界

[运行前协议](/home/grf/Documents/Codex/2026-09-12/map-denoise-dataset-pilot-v1/exploration_v6/association/PROTOCOL.md)
指定三个主例：s912101、bias=4 mm 的 g4/g8 双层及 `ghost` 单面；同时预声明24个
既有 identifiable 公开开发输入（912101/912113/912127，gap0/2/4/8，bias0/4）作为
稳健性扩展。主例已包含在24例中，不重复计数。本线没有生成数据、读取其他种子、
运行真实片区、搜索分区或改变门限。

四臂为原关联/原组×gt_layer仅拆分，交叉每组独立斜率/全组共享斜率。
每输入只从合法 XYZ、scan_id、sigma=1 mm 构造一次 V5 冻结状态；排序、扫描偏差、
gauge、法向、基、原点、XY尺度、原局部节点、逐点权重、active拟合点和输出mask
逐项相同。oracle 子组只能是某个原组的子集，不能跨原组聚合。

原关联两臂拟合结束后才读取 GT 标签；oracle API 只接受逐点整数层标签。四臂
完成后才解码完整 EVAL 评分。所有拟合都用偏差校正的原测量，不用投影点云或真实
高度、方向、间距、偏差。全部点保持原顺序与来源ID；原未支持点精确不变，仍全点评分。

## 三个主例

以下单位为 mm；间距为真实来源层各自拟合平面后在 x=y=0 的有符号差，可能涉及外推。

| 输入 | 关联/斜率 | 表面 MAE | 对应点 RMS | 同 XY 间距 |
|---|---|---:|---:|---:|
| g4 | 原组/独立 | 0.424661 | 1.139711 | 3.666621 |
| g4 | 原组/共享 | 0.616582 | 1.233104 | 1.761917 |
| g4 | oracle/独立 | 0.357902 | 1.076054 | 4.355350 |
| g4 | oracle/共享 | 0.356217 | 1.065533 | 4.120553 |
| g8 | 原组/独立 | 0.325660 | 0.769117 | 7.851612 |
| g8 | 原组/共享 | 0.976779 | 1.420787 | 2.746261 |
| g8 | oracle/独立 | 0.254404 | 0.667856 | 8.135027 |
| g8 | oracle/共享 | 0.206685 | 0.617345 | 7.679719 |

单面主例四臂逐元素相同：MAE0.042575、对应点RMS0.058375。其原组只有一个，
常量GT标签不拆组，独立/共享模型也相同，是预期负对照。

g4/g8支持率分别0.921875/0.985677，四臂完全一致；各有768个原active拟合点。
例如g4不支持输出的点仍按原权重参与，未通过缩减评分点或选择支持集获益。

定义共享损失 L=E(shared)−E(independent)，差中之差 D=L_oracle−L_original。
g4/g8的 MAE D 为−0.193605/−0.698838；RMS D为−0.103913/−0.702181；
间距误差 D为−2.139501/−4.920096。D<0说明原关联下的共享惩罚减轻，不说明
oracle 共享的每个指标都优于 oracle 独立：g8的间距误差实际由0.135027增至0.320281。

## 仍需保留的解释限制

1. **不是等自由度实验。** 原组数G变为G'，独立模型参数3G→3G'，共享模型G+2→G'+2。
   原观测范围、总权重和输出支持相同，不代表每组信息量或可估参数相同。
2. **保留了实际秩亏。** oracle独立在g4、seed912101/912113的bias0/4共4例秩亏。
   g4主例原组5个、独立15参数；拆为8子组后24参数、秩23，其中一个子组仅2点。
   oracle共享10参数、满秩。所有oracle共享满秩，设计条件数最大27.83；oracle独立
   满秩案例条件数最高约881.49。没有删小组、改权重或加模型切换门限。
   小组斜率不可辨识不等于这些保存输出不唯一：实际投影点都是拟合点的子集，
   精确设计零空间不改变样本内预测。共享可能同时获得方差/正则化益处，不能把收益
   完全分解成排除混层的贡献。
3. **上游仍冻结且可能有误。** 纯化标签并未纠正偏差估计、局部置信权重或支持集。
   真实平行表面在这批输入中的表现不能直接外推到曲面、转角或非平行表面。
4. **GT只给诊断上限方向。** 本次更直接支持“当前关联不适合无条件共享”，但不是
   所有关联误差的完整因果分解、共享的一般定理，或可部署关联器能达到此结果的证据。
   若后续获准实现估计关联，应另冻结合法输入方法；不能使用oracle选门限或模型赢家。
5. **层距指标不是总质量。** 同XY拟合可能外推；要与有限表面误差、全点位置及实际
   输出共同读。当前并未实现双层分辨率极限扩展或独立真实几何验证。
