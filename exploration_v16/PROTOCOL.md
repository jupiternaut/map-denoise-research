# V16：空间依赖、共享斜率与分层投影的机制实验

## 问题与预测

检验 V15 空间关联收益是否通过 (A) 避免可见层比例变化被解释成真实斜率，
(B) 改善点的层归属 两条路径产生。不是新算法横评、真实采集或新的首回波模拟。

模型 h = mu_0 + a^T u + gap*K + eps，已知 sigma，零共同偏差，固定坐标轴，所有点参与输出。
总体耦合 p_lambda=(1-lambda)p(u)p(K)+lambda*p(u,K) 保持边缘分布。
当条件噪声均值为零且 Cov(u) 可逆时，总体线性回归斜率为
a_linear-a=lambda*gap*Cov(u)^(-1)Cov_*(u,K)。这不保证混合模型的解遵循此式。
有限样本单独核查精确恒等式：a_OLS=a+gap*OLS_u(K)+OLS_u(eps)。

## 评分、解释、交付

- 主指标：到有限真实表面的MAE、原来源表面等权MAE、对应点RMS、1mm参考点覆盖。
- 结构：拟合面截距间距与垂直间距、来源组间距、误归属、真实中面跨越、所选层数；单面误拆单列。
- 新输入斜率：角度与欧氏误差；准确记录已知斜率干预是否改变所选层数。
- 双层硬投影核查：来源组高度差 = 拟合截距差*(1-alpha-beta) + slope^T*(mean(u_1)-mean(u_0))。
  K=1时拟合差设零，错误二分类率记不可用，不将单面等同正确分层。
- 按种子先平均同一条件切片，再对10种子的配对差报告均值和t区间；不是跨真实场景置信保证。
- 固定斜率消除优势：支持斜率耦合路径；固定斜率后优势仍依赖lambda：支持归属路径。
- lambda=0仍明显领先或退化：原解释不完整；记录有限样本/优化/正则/选层因素，不事后更换主结果。
- 本轮不加入新求解家族、RIMLS重调参、曲面模型、GPU核、真实精度主张。
- 输出代码、事前协议、完整输入/输出/轨迹/CSV、独立数值与哈希核查、研究报告和可复现静态PNG图。
- 记录四进程阶段墙钟与进程RSS口径，不作为公平算子速度横评。
