# V17 算子：可选择复杂度的局部表面混合回归

## 输入与输出

局部观测为 `(X=[1,u1,u2], h, sigma)`。给定 sigma 仍是条件输入，不是本轮解决的盲估计问题。
输出是同一批点沿固定局部法向的分层投影；没有新增点、删点或切向位移。
统计族的法向由输入坐标固定；首回波桥接复用 V7 估计并冻结的坐标系、共同偏差及支持范围。
因此后者是条件表面模块，不能当成新的完整配准系统。

## 候选的共同几何

单面为 `h = c + a^T u + epsilon`。
双面为 `h = mu_k + a^T u + epsilon`，共享斜率，但归属概率依赖位置：

    p(h|u) = (1-pi(u)) N(h; mu_0+a^T u, sigma^2)
            + pi(u) N(h; mu_1+a^T u, sigma^2).

对同样的双面几何，用三种门控表示：

- C：`logit pi(u)=beta0`。
- L：`logit pi(u)=beta0+beta1*z1+beta2*z2`。
- R：L 加上九个固定中心的高斯 RBF。z 按训练输入的中位数和半跨度缩放。

C 是 L 的子模型，L 是 R 的子模型。优化较大模型时保留较小模型的初值，
所以在同一训练集上，扩大门控不应使最佳已保留的惩罚似然更差。
这只是一条候选保留性质，不意味着测试几何、结构保持或全局最优更好。

## 不是单纯多跑几轮

每种双面家族都直接优化同一个形式的联合目标：

    J = -sum_i log p(h_i|u_i) + (0.1/2) sum_{j>0} beta_j^2.

几何和门控同时更新，使用解析梯度。空间门控不再只依赖有限轮交替 EM 的结果。
但更强求解本身不是贡献：保留 `constant_only`、`linear_only` 和 `rbf_only`，
分别识别求解变化、表示变化和选择变化。64/13/14 个起点不是等算力比较。

## 两种全局冻结的逐例选择器

BIC-style：最小化 `2*J + p*log(N)`，p 分别为 3、5、7、16。
空间信息无用时，额外门控参数必须通过较大似然改善才能抵消复杂度惩罚。
例如 N=768 时，R 相比 L 多出的九个参数带来约 59.8 的附加评分惩罚。
混合模型在分量重合等位置具有奇异性，不能据此宣称标准 BIC 的渐近保证全部成立。
这里是可复核的 BIC-style 选择规则，而不是“正确层数证明器”。

CV：按只依赖 XY 和固定随机数的三折划分，分别重训四种模型。
用留出高度的混合负对数似然选家族，然后使用该家族的全数据拟合输出。
训练折不接受完整数据拟合参数，也不读取评价标签。
首回波桥接的上游冻结状态使用了完整输入，因此该 CV 只是条件模块的留出预测，
不是独立扫描确认或独立几何真值验证。

两者优化观测解释，不直接优化真实几何。逐点最终输出仍用后验最大归属，
它与均方损失下的后验均值不是同一决策；MAE、RMS、层间距排序不必一致。

## 单面过选的解释修正（不改本轮冻结算法）

开发集 CV 有两例选择 k=2，但两面间距仅约 7.34e-9 / 1.47e-8 mm。
它们是几乎重合的参数化，不是观察到真实几何被分裂。
原开发规则只检查 k，因而保守地选择 BIC 为主版本。
保留该选择以完成冻结确认，同时必须报告物理间距和输出差异，
不能将 `single_false_split` 字段直接翻译为“表面已经被破坏”。
将来如果修订验收，应在新开发协议中定义几何可分辨分裂，而不是在本轮测试后改口径选赢家。

## 本轮能形成什么结果

如果收益来自 L 而不是选择器，就交付 L；若选择器确实在不同条件中选出有用表示，
可以把增量定位为条件适配。若预测改善却损害几何，保留负结果，
说明似然解释与输出目标尚未一致。没有一个分支预先被指定为必须成功。
这些构造是已有混合回归与模型选择工具的具体组合，不能仅凭公式形式宣称新原理。
