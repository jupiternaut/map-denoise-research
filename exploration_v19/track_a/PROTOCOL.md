# A 线固定协议

- 上游：V18 冻结家族选择、提供 sigma、固定法向与仿射局部坐标。
- 主候选 `crossfit_gate_map`；唯一直接机制对照 `insample_gate_map`。
- S 完全原样返回，不寻找第二层。
- 三折固定种子由 V17 `folds_from_x` 决定（9170001），仅依赖 XY。
- Gate：同族测量混合似然；沿用 V17 前 12 个 deterministic starts，
  L-BFGS-B 单启动最多 324 次迭代，`ftol=1e-12, gtol=1e-8, maxls=40`。
  Gate ridge 0.1，非截距项受罚；gate 概率 clip 到 [1e-8, 1-1e-8]。
- 最终几何：固定 prior 的混合似然，不裁切点、不给点修改权重；六个启动，
  分别为 V18 几何、gate 几何中位数、OLS 加 0.5/1/2/4 sigma 间距。
  单启动最多 324 次迭代；同一优化容差；间距约束 >=0。
- 家族和 sigma 不能根据真实层数、GT 或确认误差改变。
- 主比较保留 V18 retained MAP。同输入/上游，报告表面距离、对应点 RMS、
  原来源层等权误差、间距与跨中面比例，以及每例耗时；不能只报内部似然。
- 单位测试和少量已暴露开发 case 仅用来验证实现与估计 CPU 预算。
- 开发/确认输入由主代理统一 manifest、哈希与种子。进入确认前冻结源文件，
  确认后不改参数；无论正负结果，保留全部例子。
- 使用外部准确模型的 case 仅作为诊断，不算部署选择器结果。当前 API 无 GT 字段。
- 本轮不写导师简报，不更改历史 run，也不主动 Git commit/push。
