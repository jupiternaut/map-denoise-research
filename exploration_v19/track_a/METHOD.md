# A 线：交叉拟合门控与确定点云输出

## 机制构造

保持 V18 选择的 S/C/L/R 几何/门控家族。对于双面家族，将观测分为三个
仅由 XY 和固定随机种子产生的折。在其余两折独立拟合同族高斯混合回归，
再只使用留出点的 XY 预测其属于上层的先验概率 `pi_i`。**不将全样本后验
作为训练标签，不让该点的高度直接参与其 gate 的训练。**

固定这些先验后，在全部测量高度上最小化真正的混合观测负对数似然：

```
-sum_i log[sum_k pi_ik exp(-(y_i - mu_k - u_i^T a)^2 / (2 sigma^2))]
```

几何自由度为两个截距和一套共享斜率；用非负间距参数防止标签交换。
最终重新计算含测量高度的后验，MAP 投影到选择的表面，保持 N 行/点身份。
法向和点的 XY 不变，没有高置信截断或后验阈值筛选后重拟合。

直接机制对照：同一 gate 训练器使用全部输入训练，然后进行同样固定先验
几何拟合、MAP 输出。两者都是候选程序；V18 原始 retained MAP 是外部冻结底座，
不会因 A 线内部对照不佳而被移除。

## 能与不能回答的问题

此实验检验减少 gate 的逐点自拟合是否能改善确定几何输出。交叉拟合会减少每个
gate 的训练样本，并产生分折先验差异，所以不是纯净的单一因果变量开关。
家族选择仍来源于全输入 V18，几何最终仍由全部高度联合拟合；**不是全流程独立
确认，也不是保证无偏估计。** 未主张分层一定改善。

S 家族原样输出，不另开层数搜索，不用 evaluator GT，不自行估计 sigma。
此构造仍只覆盖固定法向局部平行面，不作为 3DGS、真实地图或独立真值成果。

## API

`run(x, y, sigma, baseline_model)` 返回 `crossfit_gate_map` 和
`insample_gate_map`。`x[:,0]=1`, `x[:,1:]=XY_mm/50`；`y` 和 `sigma` 为 mm。
输出含 `k, means, slope, posterior, prediction, groups` 和训练来源/求解诊断。
`prediction` 是法向坐标；调用者保留输入 XY 即得到 N×3 点云。

本模块读取 V17 既有似然、初始化与 gate 特征实现，所有旧代码/历史 run 只读。
