## 本阶段留下什么

1. **可执行构造**：同单位收益选择、逐视图成对证据、连续射线位置搜索、
   局部二次逆深度混合回归，以及图选择模块。它们都有实际输出，不只是方案。
2. **条件恢复能力**：旧恢复器的偏重恢复工作点在 −3/+3 mm 的 MSE 降幅为
   46.99%/39.02%，均为 12/12 ROI 改善；原始输入仍恶化 7.67%。
3. **候选域的可检验边界**：连续线段 Oracle 达到 74.69%/64.99%；扩大位置池
   后的联合 Oracle 为 91.94%/93.10%。它们使用评价真值，不是自动算法的成绩。
4. **具体失败定位**：宽池 Oracle、场专属 Oracle 与实际场输出不相同。
   曲面拟合与输出选择均有缺口；自渲染可见性未形成整体提升。
5. **可读、可核对的证据**：原协议、报告、正负结果、汇总表、测试、科研图
   和事后诊断边界一起保留。没有把历史负结果改写成新成功。

“多假设几何修订”是当前工作的一种描述性名称。经验测度推前、概率过程组合、
局部到整体的相容性是数学解释或后续方向，不是本轮已证明的新理论。
见 [方法定位](METHOD_POSITIONING_20260928.md)。

## 指标口径

对每个固定源点行，取输出到有限激光参考点集的最近邻距离，平方后平均；
再按 ROI 和场景等权汇总。改善率为 `100 * (1 - MSE_method / MSE_identity)`。
原始输入 MAE 为 0.561966 mm、MSE 为 0.753165 mm²，汇总 MSE 开方为
0.867851 mm。这不是平均逐 ROI RMSE，也不是连续真实表面的无噪真值误差。

单向距离允许多个点复用同一个参考近邻，不能单独保证完整性、层身份或拓扑。
Oracle 上限仅针对各自候选域与当前评分；宽池与场专属池并非嵌套集合，
二者的误差差值不是失败原因的因果百分比分摊。新增 ±3 mm 搜索位置与已测注入幅度
重合，尚需非网格偏移才能判断该覆盖增量的迁移。

## 可以马上运行的检查

在仓库根目录，仅 Python 标准库：

```bash
python -B publication/verify_replay_20260928.py
```

这会检查公开文件哈希、主评价 720 行的唯一性与有限数值、3 场景 × 4 ROI ×
5 条件 × 12 评价臂（7 个实际／对照、5 个 Oracle）的组合、等权汇总和 README 关键数值，
并检查本次新写导航的本地链接。
它不加载模型，不打开原机数据，也不宣称独立重建几何已完成。

具有 NumPy、SciPy 的环境可以运行以下合成机制测试。原机验证版本为
Python 3.12.13、NumPy 2.2.6、SciPy 1.15.3；不是所有平台安装性保证。
以下三个命令分别从仓库根目录运行，不需要更改当前目录：

```bash
python -B -m unittest discover -s research_snapshots/2026-09-26/multisurface-field-lab-20260926T102842Z -p 'test_field_model.py' -v
python -B -m unittest discover -s research_snapshots/2026-09-26/multisurface-field-lab-20260926T102842Z -p 'test_graph.py' -v
python -B -m unittest discover -s research_snapshots/2026-09-26/continuous-step-lab-20260926T100617Z -p 'test_segment_oracle.py' -v
```

前两个合计 14 项，第三个 9 项。其余部分测试和全数据推理依赖原机兄弟工作区、
归档数组或图像适配器，不能将默认 `unittest discover` 宣称为克隆后可独立全量运行。
本次发布核验与历史完整实验核验分别记录，见 [发布验证](REPLAY_20260928_VALIDATION.md)。
