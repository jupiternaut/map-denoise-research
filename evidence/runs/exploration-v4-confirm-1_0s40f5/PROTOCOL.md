# V4 并行构造：同面聚合、同目标热启动、真实误差分解

保留 V3 全部代码和输出。三条任务只新增本目录的文件，各自输出在 /srv 下唯一目录。

## 问题与可证伪变化

1. **聚合线**：同一 V3 graph 初估固定 bias、normal、局部支持；用校正后的原测量重估局部表面，不把旧投影结果当新独立证据。比较 independent / global / compatible。global 为无条件单面大范围拟合的损伤对照；compatible 只合并在共同坐标中相容的节点，不能链式误合并台阶。是否恢复平面统计效率而保薄层，须看结果。
2. **热启动线**：原始观测生成同一 measure surface elements、normal、质量和扫描图，graph 只给初始偏差，不改变运输目标。比较图纠偏单独输出、图偏差投影到运输轴的零步输出、零初始化六轮、图初始化两轮。balanced/unbalanced 其余参数一致，后置 local_only 完全相同且只做一次。记录所有初始化代价。
3. **真实分解线**：保留原 V3 三维混合扰动结论。新增零、法向平移、切向平移、小旋转，统一核心点/站来源/点数与目标扰动 RMS，记录实际值及偏差规范。注入坐标轴来自原输入的估计，不是真实法向；估计器只能看到扰动后的 XYZ/frame/sigma。原测量云不是独立真值，法向/切向分解是恢复已知注入量的诊断。

## 数据与阶段

- 开发阶段：V3 既有 27 合成输入（24可评分、3标量歧义）及12个既有采样/共同刚体坐标诊断。sigma=1 mm，8站×96点原规模，沿用严格第一返回有限平面生成数据。
- 真实：原6片区、2场景，sigma=2 mm；各方法相同输入，支持不足仍保留原点，全部点计分。未下载新数据或改变原片区。
- 若原型通过基本测试，在所有变体与参数冻结后运行此前未使用的3种子912201/912211/912223，24个可评分合成案例。预留种子只在确认入口运行；整个配置集一起确认，不根据其GT挑选超参，不因结果差而重跑调参。新种子仍属同一合成家族，不等于新真实场景。

## 评价和对照

保留 identity、旧 fast、Open3D ICP+旧XYZ后处理、V3 graph。后者ICP混合管线不是JRMPC/BALM，也不能代替对口强基线。此轮重点是两项机制的配对增量，不作SOTA宣称。

世界有限表面 MAE/RMS/P95、来源对应 RMS、参考采样覆盖、来源表面法向角与同XY拟合间距全部保留。间距拟合可有外推，单独说明，算法自报层数不评分。任何全局平移对齐分数仅作诊断，禁止逐层/逐帧对齐。

真实分解同步报告总XYZ恢复、构造轴方向恢复、切向恢复、零注入编辑、自响应和支持率。更接近原测量不是独立几何准确度证明，更多identity也不是算法成功。
