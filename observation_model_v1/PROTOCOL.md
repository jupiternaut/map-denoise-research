# 观测来源约束的误差修正 V1（运行前）

2026-09-12，liekkas。保留 published_outputs_v1–v3 和既有 multiscan 数据，只写新运行目录。

scan24/room 现有下载内容没有独立逐视角实测深度；不从同一模型渲染伪造独立证据。因此本轮使用现有 ETH3D 六个双站点云片区做来源误差机制实验，不声称这替代 scan24 的独立几何评价。

核心算子：选点数较多的站为固定参考（并列选较小站号），在另一站每点附近拟合参考站局部平面。用共同的小刚体误差解释点面残差，而不把每个点投影到平面。仅估计数值可观测分量，施加完整刚体变换保持单站内部距离。两块交错空间子集交叉拟合，检查在未参与该次求解的子集上是否减少点面残差；两方向都通过才输出全支持拟合，否则 identity。它只是交叉一致性启发式，不是概率安全保证。

冻结设置：局部平面16近邻，最小特征值/迹 <=0.05，匹配距离<=3倍参考站中位近邻间距；SVD截断相对阈值0.02，Huber IRLS 8次。参数不由评价真值选择。平面匹配只从当前输入计算并固定，源站点对点对应关系不提供给算法。

五对照：identity；独立点面投影；共同可观测刚体修正；交叉确认的共同刚体修正；官方 Open3D 点到点 ICP（相同参考站、距离上限，30次迭代）。最后一项是成熟配准对照，不是新算法。

真实实验：6片区×[不扰动+3种子×(法向平移5mm、局部旋转0.05度、两者、同RMS逐点噪声)]。仅扰动非参考站。参考仍是未扰动测量云，只能评价注入偏差恢复及无扰动改写，不能评价真实绝对几何。报告全部点和移动站 RMS、相对算子无扰动输出的响应；不能将更小的自身响应称作恢复正确。

额外歧义对照：构造坐标和站号完全相同的两种世界——共同偏移的单面与每站仅见一层的真实双面。算法必须输出相同；分别评价结果，检查跨子块确认是否会误认证真实层差为误差。它是机制反例，不用于调整门限后宣布通过。

只针对点云，不套用网格三角形检查。确认子集仍和拟合子集共享参考站及其误差，不能叫作第三站独立验证。
